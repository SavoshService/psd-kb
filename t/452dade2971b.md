**Пристрій / модель:** Ugreen GS-2200 (інвертор)

**Симптом / несправність:** Необхідність розпізнання мікросхеми на платі під позначкою IC11 (маркування знято або невідоме).

**Діагностика:** 
- Перевірка функціоналу компонента: це DC/DC перетворювач.
- Вхідний сигнал зв'язується з плюсом батареї.
- Вихідний сигнал забезпечує 12V для внутрішніх потреб плати (фідбек, живлення логіки тощо).

**Коди помилок:** Немає.

**Деталі та аналоги:** 
- Місце на платі: IC11.
- Запропонована мікросхема для ідентифікації/заміни: LM5164 (за твердженням автора теми).

**Покроковий ремонт:** 
1. Автор запитував у спільноти щодо маркування.
2. Проведено аналіз функціоналу (вхід з батареї, вихід 12V).
3. Автор самостійно визначив тип компонента та запропонував аналог/маркування.

**Результат:** Визначено функцію (DC/DC конвертер), запропонована мікросхема LM5164 як відповідна заміна або ідентифікація.

**Застереження / нюанси:** 
- ⚠️ потребує перевірки точність маркування LM5164 без офіційної схеми плати, оскільки це власний висновок автора теми ("сам запитав- сам відповім").
- Необхідність підтвердження підключень (вхід/вихід/земля) для повної ідентифікації перед заміною.
