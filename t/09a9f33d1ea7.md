**Пристрій / модель:** Fossibot F1200 (позначено в назві теми).

**Симптом / несправність:** Згоріла електроніка після підключення навантаження («чайник включили»).
- Згорів один транзистор YGW40N65F1.
- Згорів драйвер NCV57200 (секція нарізки синуса).
- Згоріла пара MOSFETів CRJF190N65.

**Діагностика:**
- Визначення згорілих компонентів візуально/виміром.
- Перевірка цілісності драйвера TR21867 (звониться як цілий), але планується заміна.
- Вимірювання параметрів NCV57200 для пошуку аналога: ізольована частина до 800В, дедтайм 350нс.

**Коди помилок:** У темі не вказано.

**Деталі та аналоги:**
- **NCV57200:** Оригінальна деталь (важко знайти аналог через специфічні параметри).
- **LTV3150:** Спробували запропонувати як замінник, але не підходить без зміни схеми. ⚠️ потребує перевірки сумісності.
- **NSD16241:** Знайдено як схожий варіант, але відсутній в продажу.
- **TR21867:** Визнано повним аналогом IR21867S (замінює згорілий драйвер).

**Покроковий ремонт:**
1.  Заміна згорілих транзисторів та MOSFETів.
2.  Пошук аналога для NCV57200 (відкинуто LTV3150 через необхідність зміни схеми).
3.  Перевірка доступності NSD16241 (немає).
4.  Замовлення оригінального NCV57200 на AliExpress для завершення ремонту.

**Результат:** Оригінальна деталь NCV57200 замовлена на AliExpress, залишки деталей будуть продані на OLX. Ремонт очікується після отримання запчастини.

**Застереження / нюанси:**
- Dрайвер NCV57200 має специфічні параметри (ізольована частина до 800В, дедтайм 350нс), тому прості аналоги можуть не підійти без зміни схеми.
- TR21867 можна використовувати як аналог IR21867S без змін у схемі.
