**Пристрій / модель:**  
- Realme C51, код моделі **RMX3080** (у темі також згадується Realme **RMX3830** – інша модель, для якої рішення не підтверджене).

**Симптом / несправність:**  
- Блокування мережі (carrier‑lock). Пристрій працює лише в мережі оператора, з яким був проданий, і не підключається до SIM‑карт інших операторів.

**Діагностика:**  
- У темі жодних вимірювань, тестів або логів не наведено. Визначення проблеми здійснено лише за ознакою «не працює в інших мережах».

**Коди помилок:**  
- Відсутні.

**Деталі та аналоги:**  
| Елемент | Опис |
|---|---|
| **Файл розблокування** | `RMX3080 rpmb.bin` – бінарний образ, який треба записати у розділ **RPMB** (Replay Protected Memory Block). |
| **Розділ пам’яті** | **RPMB** – спеціальний захищений розділ eMMC/ UFS, який використовується для зберігання даних про блокування мережі. |
| **Аналоги** | Для моделі **RMX3830** користувачі запитували аналогічний файл, проте в темі не надано готового образу. |
| **Інструменти** | Не вказані, проте типово для запису в RPMB використовується `fastboot` (команда `fastboot flash rpmb rpmb.bin`) або спеціалізовані програми типу **MTK Droid Tools**, **SP Flash Tool** (залежно від чипсету). |

**Покроковий ремонт:** *(висновок на основі наявної інформації)*  

1. **Підготовка**  
   - Завантажити файл `RMX3080 rpmb.bin` з вкладення теми.  
   - Переконатися, що файл саме для **RMX3080** (не підходить до інших моделей).  

2. **Режим завантаження**  
   - Увімкнути телефон у режим **Fastboot/Download** (зазвичай комбінація кнопок **Power + Volume Down**).  

3. **Підключення до ПК**  
   - Підключити телефон до комп’ютера через USB‑кабель.  
   - Переконатися, що драйвери Fastboot/ADB встановлені і пристрій розпізнається (`fastboot devices`).  

4. **Запис у RPMB**  
   - Відкрити консоль і виконати (приклад, реальна команда може відрізнятись):  
     ```
     fastboot flash rpmb RMX3080_rpmb.bin
     fastboot reboot
     ```  
   - Якщо використовується інший інструмент (наприклад, SP Flash Tool), вибрати розділ **RPMB** і вказати файл.  

5. **Перевірка**  
   - Після перезавантаження вставити SIM‑карту іншого оператора і перевірити, чи мережа підключається.  

**Результат:**  
- Для **RMX3080** файл `rpmb.bin` працює: користувач **Remontnikk** підтвердив, що «файл робочий».  
- Для **RMX3830** той самий файл не розблоковує мережу; у подальших дописах зазначено, що треба знизити версію прошивки (до Android 14) – це «профіт», тобто допомагає розблокувати мережу.  

**Застереження / нюанси:**  

- **⚠️ потребує перевірки** – у темі не вказано конкретну команду чи інструмент для запису в RPMB; користувачі повинні самостійно обрати сумісний спосіб.  
- Запис у **RPMB** – дуже чутливий процес: неправильний файл або помилковий запис може **запричинити блокування пристрою (brick)**. Рекомендується створити повний бекап прошивки перед будь‑яким втручанням.  
- Файл `rpmb.bin` прив’язаний до конкретної **модель‑коду** (RMX3080). Використання його на інших моделях (наприклад, RMX3830) **не гарантує успіху** і може пошкодити пристрій.  
- Якщо після прошивки мережа все ще заблокована, можливо, потрібне **зниження версії прошивки** (як зазначено у дописах 8‑9) або інший метод розблокування (наприклад, офіційний розблокуючий код від оператора).  
- Доступ до розділу **RPMB** часто вимагає **розблокування завантажувача (bootloader)**; у темі це не згадано, проте без розблокування запис може бути неможливим.
