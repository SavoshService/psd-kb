## Огляд теми «Оновлення програматора EMT»

| Розділ | Інформація |
|--------|------------|
| **Пристрій / модель** | **Програматор EMT (EME Mobile Tool)** – програмне забезпечення для роботи з різними мобільними пристроями (MTK, Qualcomm, Xiaomi, OPPO, ONEPLUS, VIVO, SMARTISAN, LENOVO тощо). <br>Оновлення охоплюють версії **v3.35.00 → v3.36.00 → v4.03.01 → v4.05.00**. |
| **Симптом / несправність** | У темі не вказано конкретних симптомів або поломок пристроїв. Тема присвячена **переліку нових функцій та підтримуваних моделей** у нових прошивках програматора. |
| **Діагностика** | Не проводилась. У дописах немає вимірювань, тестових даних, логів чи опису процесу діагностики. |
| **Коди помилок** | Не зазначено. |
| **Деталі та аналоги** | <details><summary>Перелік нових можливостей та підтримуваних моделей (коротко)</summary> <ul><li>**v3.35.00 (15 серпня 2023)** – додано кнопку *Dev.Manager*; Manual/Auto Mode для MTK‑модулю; підтримка широкого спектру MTK‑чипів (MT6739 … MT6893); Auto‑Mode включає Auth Service, Factory Reset, Reset FRP, Erase Userdata/FRP, Unlock/Relock Bootloader, Fix DM‑Verity Error.</li><li>**v3.36.00 (31 грудня 2023)** – підтримка Qualcomm Snapdragon 8 GEN2, 782G у OPPO/ONEPLUS‑модулі; нові ADB‑функції для OPPO/VIVO (Reset ID, Disable APP lock); розширена підтримка моделей Xiaomi (EDL, BROM/SIDELOAD, SIDELOAD), OPPO, ONEPLUS, SMARTISAN, LENOVO.</li><li>**v4.03.01 (23 вересня 2024)** – додано «Fix Demo/Enterprise (Sideload)» для багатьох моделей Xiaomi (MI CIVI 4 PRO, MI 14 ULTRA, MI 13 ULTRA, …); підтримка Enterprise/Carrier Edition для Xiaomi, OPPO, Realme.</li><li>**v4.05.00 (11 листопада 2024)** – рішення **Vivo Qualcomm «Reset ID»** для Snapdragon 870‑720‑665 та ін.; нові моделі Vivo (S15, S16, PAD AIR, IQOO NEO) та OPPO/Realme (A3X, A40, RENO12 F, REALME 12/13, C67, 12 LITE).</li><li>**v4.05.00 (оновлення 01.04.2025)** – додано OPPO‑модуль без розблокування BL; підтримка EDL‑моделей OPPO (EMMC) з рекомендацією спочатку вибирати режим **UFS**, при невдачі – **EMMC**.</li></ul></details> |
| **Покроковий ремонт** | Тема не містить інструкцій щодо ремонту конкретного пристрою. Є лише **рекомендації з використання EMT**: <br>1. Оновити програму до останньої версії (v4.05.00). <br>2. При роботі з OPPO‑моделями спочатку вибрати режим **UFS**, при помилці переключитися на **EMMC**. <br>3. Для MTK‑чипів встановити **UsbDK** (Uninstall → Install → Restart) перед використанням функцій Auto Mode. |
| **Результат** | У темі **не вказано вирішення конкретної проблеми**. Оновлення програмного забезпечення надали нові функції (Reset ID, Disable APP lock, розширений список підтримуваних моделей, покращений Unlock Bootloader) та виправили відомі баги. |
| **Застереження / нюанси** | • При роботі з MTK‑модулем необхідно встановити **UsbDK** (видалити → встановити → перезапустити). <br>• Для OPPO‑моделей (A5 2020, A9 2020, A11, A11N, A11X) **рекомендовано** спочатку вибирати режим **UFS**, при невдачі – **EMMC**. <br>• Деякі нові функції (Reset ID, Disable APP lock) працюють **без авторизації/кредитів**, тому їх слід використовувати лише на законних підставах. <br>• Підтримка нових моделей (наприклад, Xiaomi Fix Demo/Enterprise) обмежена датою випуску прошивки; після оновлення до новішої версії можуть з’явитися нові моделі. <br>• При використанні **Auto Mode** у MTK‑модулі важливо, щоб час ПК‑клієнта був коректним – інакше вхід у програму може бути заблокований. |
| **Примітка** | Якщо потрібна діагностика або ремонт конкретного пристрою, необхідно створити окрему тему з описом симптомів, вимірювань та кодів помилок. У даній темі представлена лише інформація про оновлення програмного забезпечення EMT. |
