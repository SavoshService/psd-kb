**Пристрій / модель:** Nokia 150 (TA‑1235)  

**Симптом / несправність:** Відсутній український мовний пакет у прошивці. Користувач просить надати прошивку з українською локалізацією.  

**Діагностика:**  
- **SWVer** – `GEMINIVAL.20.08.11.p1` (версія програмного забезпечення).  
- **FLASH** – `00C2 : 0025 : 0036 : 0000` (версії різних flash‑модулів).  
- **PRDC** – `059Z0X8` (продукт‑код, який використовується для підбору прошивки).  
- **NCK** – 20‑цифровий код мережі (не використовується для прошивки, лише для розблокування).  
- **PROV** – `24407000` (провайдер/оператор, можливо впливає на предустановлені аплікації).  

Ніяких вимірювань, тестів чи логів помилок не наведено.  

**Коди помилок:** – немає.  

**Деталі та аналоги:**  
- **PRDC `059Z0X8`** – типовий код для Nokia 150, TA‑1235, який використовується в інструментах (наприклад, Nokia Flash Tool, Nokia Software Recovery Tool) для автоматичного підбору прошивки.  
- **SWVer `GEMINIVAL.20.08.11.p1`** – остання офіційна прошивка (з серпня 2020 р.) для даної моделі, без української локалізації.  

**Покроковий ремонт:** – у темі не описано жодних дій.  

**Результат:** не вирішено в темі.  

**Застереження / нюанси:**  
- ⚠️ **Використання невірної прошивки** (наприклад, з іншим PRDC або FLASH‑версією) може призвести до «бріків», втрати даних або навіть «запалення» пристрою.  
- Перед прошивкою необхідно **зробити резервну копію** важливих даних (контакти, SMS, налаштування).  
- При прошивці слід користуватись **офіційними інструментами** (Nokia Software Recovery Tool, Nokia Flash Tool) та **офіційними файлами** з сайту HMD Global або перевіреними репозиторіями (наприклад, XDA‑Developers).  
- Якщо потрібна **українська локалізація**, її можна додати після прошивки за допомогою **Nokia Language Pack** (зазвичай включається в офіційний пакет прошивки для регіону UA/RU). Потрібно переконатися, що пакет сумісний з версією `GEMINIVAL.20.08.11.p1`.  
- При роботі з **NCK** (Network Control Key) слід пам’ятати, що його введення без дозволу оператора може порушувати умови використання мережі.

Тому подальша допомога потребує пошуку відповідного українського пакету прошивки (з урахуванням PRDC `059Z0X8`) у відкритих репозиторіях або у офіційного представника Nokia.
