## Розбір теми «Hisense 32B6600PA, Android Recovery, прошивка по USB»

| Пункт | Інформація з теми |
|------|-------------------|
| **Пристрій / модель** | **Hisense 32B6600PA** (Android‑TV) |
| **Main Board** | TP.MS6683T.PB732 |
| **LCD‑модуль** | JHD315V1H71‑T0L1\S0\FM\ROH |
| **Симптом / несправність** | - При ввімкненні одразу переходить в **Android Recovery**.<br>- Кнопка **Power** на панелі та пульт **не реагують**.<br>- Інші кнопки на панелі відсутні/не працюють.<br>- Телевізор «зависає», працює нестабільно після попереднього «factory reset». |
| **Діагностика** | - Ніяких вимірювань (напруги, опорів) у темі не зазначено.<br>- Оцінка стану: **проблема завантаження** → підозра на **eMMC** (пам’ять) та/або пошкоджену прошивку. |
| **Коди помилок** | В темі не вказані жодні коди помилок. |
| **Деталі та аналоги** | - Для даної моделі типова процедура **Android Recovery → Update from USB**.<br>- Потрібна **офіційна прошивка** (зазвичай у вигляді *.zip* або *.img*), яку розповсюджують на форумах/сайтах підтримки.<br>- При відсутності працюючих кнопок часто використовують **зовнішню USB‑клавіатуру** для навігації в Recovery. |
| **Покроковий ремонт** | 1. **Знайти та завантажити** правильну прошивку для Hisense 32B6600PA (зазвичай з офіційного сайту або довіреного ресурсу).<br>2. Підготувати **USB‑флешку**: формат FAT32, скопіювати файл прошивки у кореневу папку.<br>3. Підключити флешку до USB‑порту телевізора.<br>4. Увійти в **Android Recovery** (вже автоматично при включенні).<br>5. За допомогою **зовнішньої клавіатури** (або працюючих кнопок) вибрати **«Apply update from USB»** → вибрати файл прошивки → підтвердити.<br>6. Дочекатися завершення процесу (зазвичай кілька хвилин, індикатор прогресу у Recovery).<br>7. Після успішного прошивання виконати **Factory data reset** (знову через Recovery) – це стирає залишкові дані та дозволяє «чистий» старт.<br>8. Перезавантажити телевізор, пройти первинне налаштування.<br>9. За потреби встановити **оновлення OTA** (наприклад, 920 МБ, як зазначив користувач night_hawk). |
| **Результат** | - **StarService**: після використання зовнішньої клавіатури та factory reset телевізор працював, проте був нестабільний.<br>- **night_hawk**: після прошивки з флешки (два проходи) телевізор «ожив», після налаштувань отримав OTA‑оновлення ≈ 920 МБ – **повна працездатність**. |
| **Застереження / нюанси** | - **Правильна прошивка**: використання прошивки, не призначеної саме для TP.MS6683T.PB732 / Hisense 32B6600PA, може привести до **брікінгу**.<br>- **Формат флешки**: FAT32, без зайвих папок, іменування файлу згідно інструкції (часто `update.zip`).<br>- **Живлення**: під час прошивки не вимикайте живлення – ризик пошкодження eMMC.<br>- **eMMC**: якщо після прошивки проблеми залишаються (зависання, постійний Recovery), можлива фізична **помилка eMMC** – потребує заміни плати або модуля пам’яті.<br>- **Клавіатура**: у багатьох Android‑TV Recovery працює лише USB‑клавіатура (не всі пульти).<br>- **Бекап**: перед прошивкою бажано зробити копію поточної прошивки (зняття eMMC через програматор) – у темі не згадувалося, але це загальна рекомендація. |
| **⚠️ потребує перевірки** | - Підозра на eMMC (зазначена користувачем) не підтверджена вимірюваннями; можливо, проблема лише у пошкодженій прошивці. |

---  

### Короткий висновок
Тема містить достатньо інформації, щоб сформувати типову схему відновлення Android‑TV Hisense 32B6600PA, що «застряг» у Recovery. Основний шлях – **завантажити офіційну прошивку, прошити через USB у Recovery, виконати factory reset і, за потреби, OTA‑оновлення**. При відсутності працюючих кнопок необхідна **USB‑клавіатура**. Якщо після цих дій пристрій продовжує поводитися нестабільно, варто перевірити **eMMC** на фізичні дефекти.
