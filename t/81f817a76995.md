**Пристрій / модель:** Apower AP2000 (модель 2600W), EG8026, EG1615_Lite, AllPowers Volix P300, AP1000, CTOLITY APower2000.
**Плата / контролер:** EG8026 (Customer code 2400W vs 2000W), EG1615 (BMS), N32G430C8L7 (процесор), ACM32F070KBU7 (MCU).
**Маркування:** PDF розпіновка вказує 2200W. ⚠️ Маркування Customer code 2400W / 2000W на новій та рідній платах відрізняється.

**Симптом / несправність:**
- Пошкодження від зустрічного струму: вибиває високовольтні транзистори/драйвери, діоди з резисторами, конденсатори; спалахування плати управління при високій напрузі DC шини.
- На Volix P300 після заміни не показує вихідну потужність.
- Після увімкнення станція переходить на роботу за профілем 1 (заводським) в Advanced settings — Inverter configuration parameters, навіть якщо налаштування було 0.
- Зарядка максимум 35 Вт, але індикація вірна.
- Нема індикації вихідної потужності.
- Контролер завис, не виводиться конфігурація, не йде на зв'язок.
- ДС шина напруга плавно підіймається до 500 В без навантаження, інвертор йде в захист на декілька секунд (цикл).
- Навантаження не відображається на дисплеї.
- Read-out protection (ROP) включено.
- Norton MCU — core блокує запит на читання.
- Показує заряд 4 Вт, напруга АКБ піднімається.
- Працює при навантаженні >= 100Вт.
- Без навантаження ДС піднімається до 500В, інвертор у захист на декілька секунд.
- Прошивка не почалася або нічого не помічено після запуску. Повна тиша в EG1615.
- Зміни конфігурації (110V/60Hz) не зберігаються після циклу живлення, повертаються до значень 220V.
- При вимкненому екрані зарядка не починається (горить червона лампа на EG8026).

**Діагностика:**
- Електроліт 270uF 500V. ⚠️ Конденсатор 500В поруч з ним та резистор на 100 Ом змінено (різні версії станції).
- Потужність AP2000 — 2600W, EG8026 (нова) — 2000W, EG8026 (рідна) — 2400W, Volix P300 зарядка — 35 Вт. ⚠️ PDF від Yijing Microelectronics Co., Ltd. вказує 2200W.
- 21 % (прогрес прошивки до зависання контролера).
- 35 Вт (граничне значення зарядки).
- 500 В (напруга ДС шини без навантаження).
- 430 В (напруга високої DC шини скачеть в районі).
- 100 Вт (порог навантаження для стабільної роботи).
- 220 В / 223В (вихідна напруга).
- 34В (напруга BMS, LiFePo очікується ~36В).
- AC Current без навантаження 3.4А.
- AC Current при навантаженні 500Вт 5.88А.
- температура радіатора >60°C.
- Hall current calibration: 6400 (фактичне), 2230 (бажане), 0.0 (після WRITE). ⚠️ Калібрувальні значення після прошивки не змінюються (з нових мікросхем).
- EG8026 мигає червоним-зеленим при CH341 оригінальному.

**Коди помилок:**
- Профіль 1 (заводський < 2000W).
- Профіль 0 (клієнтський, імпорт конфігурації).
- UART десинхронізація.
- EG8026 мигає червоним-зеленим при CH341 оригінальному.

**Деталі та аналоги:**
- USB-UART на чипі CH340G для оновлення прошивки.
- Перехідник з опторозв'язкою RT232RL не працює (0%).
- TL431 (SOT23) з маркуванням 431 — насправді TL432. ⚠️ Причина: 431 з переплутаними ногами.
- Резистори 390к + 360к (компоненти ДС шини).
- CH341A (SN341A), CH340G, USB/UART.
- Оригінальна EG куплена на OLX у Андрія.
- Використання налаштувань з рідної плати для імпорту в нову.
- Можливість використання програматора EG link.
- Прошивка від AP2000/AP1000 (однакова для EG8026/EG1615).
- EG1615_Lite V2.4.0 (коректний експорт/імпорт конфігурації), EG1615_Lite V2.3.0.
- EG8026_APP_v3.2.230907_10s220V2400W_C051_WEIAN_7_0xD5E6.7z.
- EG1615_APP_v3.1.230803_10s220V1500W_C051_WEIAN_2_UPS.7z.
- Інструмент Firmware Update. "Apower2000 налаштування EG1615 / EG8026".

**Покроковий ремонт:**
1. Заміна IGBT на виході + EG8026.
2. Імпорт налаштувань з рідної плати (Device information - Inverter configuration - 0 - Write; Advanced settings - імпорт/параметри - Save all). Результат: перехід на профіль 1 (2000W) після увімкнення.
3. Звернення до технічної підтримки за оригінальною прошивкою для моделі.
4. Оновлення прошивки через Firmware Update. Результат: EG став 1:1 як оригінал, перезаписалися значення в профілі 1, AP2000 працює коректно.
5. Для Volix P300: надання скріншоту з Device information (конфіг злитий).
6. Оновлення прошивки через CH341/CH340G/SN341A.
7. Перепайка нового контролера після зависання на 21%.
8. Зміна налаштувань на ПК (вольтаж по DC bus).
9. Підключення до іншого порту USB, використання без подовжувача.
10. Повний цикл заряд до 100% + розряд до 0% на постійній навантаженні з підключенням ваттметра; відключення від мережі для охолодження радіатора при 50-55% ємності батареї.
11. Спроба записати значення OUTPUT CURRENT CALLIBRATION та HALL CURRENT CALLIBRATION.
12. Вручну змінювати не треба, тільки прошивка.

**Результат:**
- Новий EG став 1:1 як оригінал, всі значення в профілі 1 перезаписані.
- AP2000 працює коректно після оновлення.
- Використання прошивки під Apower 1000 на Xpower та UAPOW — працює без проблем.
- ⚠️ Конфігурація зберігається у firmware, значення перезаписуються після оновлення.
- Перевірити значення калібровок перед першим вмиканням (щоб не спалити інвертор).
- EG8026 (нова і родна) відрізнялися лише Hall Current calibration + прошивкою.

**Застереження / нюанси:**
- Не прошивайте нову EG8026 для Volix P300, поки не знайдете версію firmware.
- Використовуйте ту ж прошивку що й Apower2000 або AP1000; на вкладці eg8026 знайти фото заводських налаштувань і вписати їх.
- Калібрувати на 1 вкладці eg8026, дивитись коефіцієнт як на інших станціях ap1000.
- Перевірити прогар під релюшкой.
- Заміна: ОУ, датчики струму, 431, оптопари (без результату).
- AP2000: Bus Voltage Calibration Value неадекватне -> зірвало кришу конденсатора.
- XP1000: Output Carrent Calibration Value неадекватне -> потужність заряду 1500Вт.
- Перед прошивкою обов'язково вийняти процесорну плату з інвертора.
- Звернутися до техпідтримки за версію firmware як у оригінальному EG (для моделі).
- нагрів радіатора високовольтної частини — норма.
- EG1615 відповідає за акумулятор (вольтаж, потужність зарядки, розрядки).
- ⚠️ Вручну змінювати не треба, тільки прошивка.
