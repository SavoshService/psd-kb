**Пристрій / модель:**  
- **Toolkitrc M9** – портативна зарядна станція (акумуляторна) для дронів.  

**Симптом / несправність:**  
- Немає поломки. Користувач потребує **ідентифікації PWM‑чипа** (SO‑8) під конектором micro‑SD, маркування на корпусі закінчується на **“83b”**.  

**Діагностика:**  
- Ніяких вимірювань чи тестів у темі не проводилось. Питання стосується лише візуального розпізнавання маркування.  

**Коди помилок:**  
- Відсутні.  

**Деталі та аналоги:**  
| Маркування (запит) | Відповідь у темі | Опис компонента | Основні характеристики |
|--------------------|------------------|-----------------|------------------------|
| …83b (нечітке)     | **RT6283B**      | PWM‑контролер, 8‑вивідний (SO‑8) | • Широкий діапазон вхідної напруги 4,5‑30 V  <br>• Регульований вихідний струм (зазвичай 0,5‑5 A) <br>• Вбудований захист від короткого замикання та перенапруги <br>• Частота перемикання 20‑200 kHz (залежить від налаштувань) |
|                    |                  | Аналоги: **RT6280**, **RT6281**, **RT6282** (схожі функції, різна потужність) |  |

**Покроковий ремонт:**  
- У темі не описувались жодні дії з ремонту чи заміни.  

**Результат:**  
- Чип **ідентифіковано** як **RT6283B** (за відповіддю користувача *skljarik*).  

**Застереження / нюанси:**  
- **⚠️ потребує перевірки** – маркування “83b” може відповідати й іншим виробникам (наприклад, RT, Richtek, або інші). Рекомендовано перевірити повний номер на корпусі (наприклад, “RT6283B‑xxx”) або порівняти розташування виводів з даташитом, щоб уникнути помилок при заміні.  
- При демонтажі чипа в SO‑8 потрібен **паяльник з температурою 300‑350 °C** та **мідна паста** або **припойна станція**; без належного обладнання легко пошкодити оточуючі елементи плати.  
- Якщо планується заміна, слід враховувати **максимальний струм виходу** та **напругу живлення** у вашій конкретній конфігурації зарядника (зазвичай 12 V‑24 V).  
- При роботі з зарядними станціями слід дотримуватись **безпеки щодо високих струмів** та **запобігати коротким замиканням** на виходах.
