**Пристрій / модель:** Jackery Explorer 1000EU

**Симптом / несправність:** Пошкодження силових компонентів (пробиті вихідні IGBT та MOSFET на вході) після дії зустрічного струму. Оригінальний термоінтерфейс під транзисторами відсутній у вигляді отворів для кріплення, компоненти закріплені на радіаторах без видимих отворів (припускається використання термоклею або спеціальної пасти).

**Діагностика:**
*   Візуальний огляд радіаторів: відсутність заводських отворів під кріплення.
*   Перевірка можливості демонтажу транзисторів без пошкодження корпусу (вимагає нагрівання).

**Коди помилок:** не вказано

**Деталі та аналоги:**
*   **Тип кріплення:** М3 (різьба).
*   **Термоінтерфейс:** Керамічні термопрокладки, силіконові прокладки, гумові термопрокладки.
*   **Інструменти:** Свердло 2.5 мм або 3 мм, метчик М3.

**Покроковий ремонт:**
1.  Демонтаж радіаторів для доступу до транзисторів.
2.  Нагрівання радіатора до температури ~200°C на паяльній станції для зняття транзисторів без пошкодження корпусу (оригінальний термоінтерфейс одноразовий, компоненти сидять «намертво»).
3.  Свердління отворів у радіаторі (використано свердло 2.5 мм або 3 мм).
4.  Нарізка різьби М3 в отворах.
5.  Монтаж нових термопрокладок (силиконових або керамічних) та кріплення транзисторів через гайки/винти.

**Результат:** Демонтаж пошкоджених компонентів завершено, радіатори підготовлені для повторного монтажу. Вибір типу термопрокладки (кераміка чи силікон) та точний діаметр отвору ще не фіналізовано в темі («подивлюся, що краще стане»).

**Застереження / нюанси:**
*   ⚠️ потребує перевірки: Для зняття транзисторів без пошкодження корпусу необхідно нагрівати радіатор до 200°C.
*   ⚠️ потребує перевірки: Існують суперечливі рекомендації щодо діаметра отвору (2.5 мм проти 3 мм) та типу термопрокладки (кераміка, силікон, гума) без офіційних даних виробника.
*   Оригінальний термоінтерфейс одноразовий, повторне використання старого неможливе.
