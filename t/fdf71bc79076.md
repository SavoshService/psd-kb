## Розбір теми «База Qualcomm Firehose Loader для Nokia»

| **Розділ** | **Інформація** |
|------------|----------------|
| **Пристрій / модель** | **Nokia 1.4** (код платформи **TA‑1322**) |
| **Симптом / несправність** | - При включенні зависає на логотипі **Android**.<br>- Не завантажується ОС.<br>- Доступні режим **Fastboot**, **Recovery** (только 3 пункти, без *Hard Reset / Wipe data*) і **EDL (9008)**.<br>- USB‑debugging у *Developer options* не ввімкнено → ADB не працює.<br>- Завантажувач (bootloader) заблокований → команди Fastboot (`fastboot oem unlock`, `fastboot flashing unlock` тощо) не виконуються. |
| **Діагностика** | - Перевірка режимів: телефон успішно переходить у Fastboot, Recovery та EDL (9008).<br>- Відсутність реакції на ADB (через вимкнене USB‑debugging).<br>- Спроба розблокування через Fastboot без успіху (bootloader заблоковано). |
| **Коди помилок** | В темі не вказані конкретні коди помилок (наприклад, **0xDEAD**, **0x9008** – лише позначення режиму EDL). |
| **Деталі та аналоги** | - У темі розміщені файли **Firehose** для інших моделей: <br>  • `prog_emmc_firehose_8937_ddr_TA-1157.mbn` – Nokia 4.2 (TA‑1157).<br>  • `prog_emmc_firehose_Sm6125_lite_ta-1234.elf` – Nokia 5.3 (TA‑1234).<br>  • Для **TA‑1322** (Nokia 1.4) файл **Firehose** не знайдено. |
| **Покроковий ремонт** | У темі не описано реальних кроків ремонту, лише пропозиції: <br>1. **JTAG**‑програмування (пряме підключення до чипа).<br>2. Використання платформи **“fenilo”** (платний сервіс, “за кредити”).<br>3. Спроба знайти/створити **prog_emmc_firehose.mbn** для TA‑1322 і прошити через EDL. |
| **Результат** | **Не вирішено в темі** – користувач залишився без готового Firehose‑файлу і без успішного способу розблокувати завантажувач. |
| **Застереження / нюанси** | - **⚠️ потребує перевірки**: пропозиція “fenilo за кредити” – це комерційна пропозиція, достовірність і безпека сервісу не підтверджені.<br>- JTAG‑програмування вимагає спеціального обладнання та навичок; без правильного файлу Firehose навіть JTAG може не допомогти, якщо чип захищений (Secure Boot).<br>- При роботі в режимі **EDL (9008)** без відповідного Firehose‑завантажувача пристрій не піддається прошиванню – необхідно знайти або створити файл, сумісний з **SM4350/SM4351** (чип, який використовується у Nokia 1.4).<br>- Відсутність *Hard Reset / Wipe data* у Recovery ускладнює спроби відновлення через стокове меню. |
| **Додаткова інформація** | - У темі немає жодних вимірювань (напруга, опір, стан ліній), логів з QPST/QFIL, чи скріншотів з EDL‑режиму. <br>- Для подальшого пошуку Firehose‑файлу можна спробувати: <br>  • Офіційні прошивки від **Nokia** (розпакувати `update.zip` і пошукати `prog_emmc_firehose*.mbn`).<br>  • Спільноти XDA, GSM, Reddit – іноді користувачі діляться кастомними Firehose‑файлами.<br>  • Створення власного Firehose‑завантажувача за допомогою **Qualcomm QFIL/QPST** та **Sahara**‑запитів (вимагає глибоких знань). |

---  

**Висновок:** Тема містить лише запити на файл Firehose для Nokia 1.4 (TA‑1322) та опис симптомів, без реального діагностичного процесу чи успішного ремонту. Для подальшого вирішення необхідно знайти/створити відповідний Firehose‑завантажувач або скористатися апаратним JTAG‑програмуванням. У поточному стані питання залишилося відкритим.
