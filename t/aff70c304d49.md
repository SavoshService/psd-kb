**Застереження / нюанси**  
- Процедура **видалення KnoxGuard** недоступна на моделях Samsung **U/U1** (наприклад, S24 U, S24 Ultra).  
- Процедура **читання кодів** недоступна на **Samsung Galaxy Tab S6 Lite**.  
- Оновлені процедури Set KnoxGuard State, Patch KnoxGuard і Set RMM State EUB сумісні з більшою кількістю старіших мікропрограм (SM‑A530*, SM‑A730*, SM‑A750*, SM‑M205*).
