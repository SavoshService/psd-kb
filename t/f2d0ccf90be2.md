**Пристрій / модель:** Bluetti AC70 (у дописі 5 уточнено, що це не AC70P).

**Симптом / несправність:** При ввімкненні розетки вмикаються самостійно; станція показує повідомлення про перегрів інвертора після невдалого оновлення прошивки.

**Діагностика:** Апаратна перевірка не виявила збоїв (конкретних вимірювань у темі немає).

**Коди помилок:** Помилка перегріву інвертора; згадано код "002" ⚠️ потребує перевірки.

**Деталі та аналоги:** 
- Процесори: AT32F403ARCT7 (інвертор), AT32F415RCT7 (панель).
- Для читання через J-Link потрібно обрати GD32F403RC (стандартний процесор не підтримується, потрібна хитрість з ідентифікатором).
- Для панелі AT32F415RCT7 обмежено об'єм використовуваної Flash.

**Покроковий ремонт:** 
Не наведено в темі (описується лише пошук прошивки, фізичних дій не зафіксовано).

**Результат:** не вирішено в темі.

**Застереження / нюанси:** 
- При читанні процесора AT32F403ARCT7 через J-Link потрібно обрати GD32F403RC (інший ідентифікатор).
- Для панелі AT32F415RCT7 обмежено об'єм використовуваної Flash.
- У темі згадується прошивка для AC70P, але користувач уточнює, що модель без літери P ⚠️ потребує перевірки сумісності.
