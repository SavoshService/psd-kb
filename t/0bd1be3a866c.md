**Пристрій / модель:** 
A-POWER AP2000 (інверторна частина), A-POWER AP1000 (використовувався як донор для конфігурації). Контролери: EG8026 (контролер живлення), EG1615 (контролер), EG1160 (два пробитих драйвера).

**Симптом / несправність:** 
Відсутня заводська конфігурація або вона некоректна; некоректна калібрування показників на дисплеї (завищене значення потужності); неправильне заповнення ШІМ, мігання; дані налаштувань зберігаються лише в РАМ (RAM), після перепідключення чіпу від живлення — повернення до дефолту; захист активується при 1кВт (максимальна потужність станції 2600W).

**Діагностика:** 
- Виміри навантаження: реальне 100Вт → дисплей показує 270W; реальне 500Вт → дисплей показує 1380W.
- Калібрувальні значення (зчитані): калібрування напруги мережі = 4179; калібрування напруги шини = 2791; калібрування вихідної напруги = 4125; калібрування вихідного струму = 1800; калібрування струму датчика Холла = 2230.
- Перевірка конфігурації Inverter Configuration: значення 0 (дефолт) або 1 (користувача).

**Коди помилок:** 
ОВЕРЛОАД (спрацьовує при подачі 1кВт навантаження).

**Деталі та аналоги:** 
- Контролери: EG8026, EG1615, EG1160.
- Прошивка/Програми: EG1615_Lite (версії EG1615_Lite_V2.2.0_EN.exe.zip, EG1615_Lite_V2.3.2.rar з підтримкою англійської).
- Інструменти: J-Link (для зчитування/запису).
- Донори: Дамп конфігурації з A-POWER AP1000 використовується для запису коефіцієнтів.

**Покроковий ремонт:** 
1. Заміна контролера EG8026 та двох драйверів EG1160 (плата стартанула).
2. Підключення J-Link до контролера EG1615.
3. Зміна конфігурації інвертора з 0 на 1 (дефолт → користувача/Advanced Settings).
4. Запис калібрувальних коефіцієнтів з дамп A-POWER AP1000.
5. Перевірка команди Read All.
6. Модифікація програми EG1615_Lite (переклад інтерфейсу).

**Результат:** 
Станція працює, адекватно заряджає банки, бачить вихідну напругу та навантаження. Налаштування зберігаються після запису, але є нюанс зі скиданням (див. Застереження).

**Застереження / нюанси:** 
- ⚠️ **Втрата налаштувань:** Дані Advanced settings зберігаються в РАМ, після першого відключення живлення/ресету чіпу — повернення до дефолту.
- ⚠️ **Конфігурація:** Значення Inverter Configuration має бути 1 (користувача), а не 0 (дефолт).
- Налаштування напруги: Дефолт 220В, може змінюватися до 230В.
- Купівля контролера EG8026 можлива у приватних осіб (наприклад, «пан Андрій» на OLX).
