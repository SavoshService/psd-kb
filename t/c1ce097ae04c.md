**Пристрій / модель:** EcoFlow Delta 3 Pro

**Симптом / несправність:** Станція не заряджається від зовнішнього джерела живлення.

**Діагностика:** 
- Розбирання корпусу пристрою.
- Видалення інвертора для доступу до плати.
- Візуальний огляд секції, що відповідає за зарядку (аномалій не знайдено).
- ⚠️ потребує перевірки: У темі не наведено результатів вимірювань (напруга на конденсаторі, стан АПФЦ/шини), лише запропоновано виконати ці заміри.

**Коди помилок:** Error 111 (помилка 111).

**Деталі та аналоги:** Інформація про конкретні деталі, плати чи донорські вузли відсутня.

**Покроковий ремонт:** 
1. Отримання пристрою з діагнозом "не заряджається".
2. Розбирання корпусу.
3. Вилучення інвертора.
4. Огляд плати живлення/зарядки.

**Результат:** не вирішено в темі (проблема залишилась без підтвердження усунення).

**Застереження / нюанси:** 
- Помилка 111 може вказувати на проблему з логікою контролера або живленням шини, що потребує електричної діагностики.
- Візуальний огляд без замірів параметрів (запуск АПФЦ, напруга конденсаторів) є недостатнім для точного визначення несправності.
