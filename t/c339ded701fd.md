## Розбір теми «Шукаю програму MAX17320 EV Kit GUI для роботи з мікросхемою MAX17320 через EV2400»

| Пункт | Інформація |
|-------|------------|
| **Пристрій / модель** | • **MAX17320** – мікросхема моніторингу батареї (Li‑ion/Li‑poly). <br>• **EV2400** – програматор/адаптер, який використовується для підключення до MAX17320. |
| **Симптом / несправність** | Користувач **Rostyk.07** не може отримати програму **MAX17320 EV Kit GUI** (файл *.msi* або *.zip*) для читання статусу батареї через EV2400. <br>• Проблема з реєстрацією на офіційному сайті (поле «Назва компанії» блокує продовження). |
| **Діагностика** | У темі не вказано жодних вимірювань, сканувань I²C‑ліній чи логів програми. Є лише спроба завантажити архів **MAX17320EVKitGUISetup_v1_0_18.zip** (доданий користувачем **Yur4uk**) і повідомлення про невдалу реєстрацію. |
| **Коди помилок** | Відсутні. |
| **Деталі та аналоги** | • Офіційний дистрибутив програми – **MAX17320EVKitGUISetup_v1_0_18.zip** (зазвичай розповсюджується на сайті Maxim Integrated). <br>• Для роботи програми потрібен **програматор**, сумісний з MAX17320 (у відповіді **R_Pavel** наведено зображення **max17320.jpg**, що вказує на спеціальний програматор, а не EV2400). |
| **Покроковий ремонт** | У темі не описано конкретних кроків ремонту. Є лише рекомендації: <br>1. Спробувати завантажити архів з офіційного сайту (виконано користувачем **Yur4uk**). <br>2. При реєстрації заповнити поле «Назва компанії» (проблема не вирішена). <br>3. Зауваження, що **EV2400** **не сумісний** з даною програмою (повідомлення **R_Pavel**). |
| **Результат** | **не вирішено в темі** – користувач не отримав працездатної програми, а інша думка стверджує, що EV2400 взагалі не підходить. |
| **Застереження / нюанси** | • **⚠️ потребує перевірки** – твердження, що «програма ніколи не буде працювати з EV2400», потребує підтвердження технічними даними (специфікації інтерфейсу EV2400, підтримка I²C‑/SMBus‑з’єднання). <br>• При реєстрації на сайті Maxim необхідно заповнювати всі обов’язкові поля (наприклад, «Назва компанії»), інакше завантаження блокується. <br>• Якщо потрібен саме **MAX17320 EV Kit GUI**, варто використовувати **офіційний програматор Maxim (MAX17320 Development Kit)**, а не EV2400, якщо останній не підтримується. |

---  

**Висновок:** У темі представлена лише запит на програму та коротка дискусія про сумісність EV2400. Технічних вимірювань, кодів помилок чи конкретних кроків діагностики/ремонту немає. Питання залишилося відкритим, і для подальшого вирішення слід уточнити сумісність EV2400 з MAX17320 EV Kit GUI або придбати рекомендований програматор.
