## Огляд теми «Оновлення ПЗ Infinity‑Box»

| Пункт | Інформація, витягнута з теми |
|-------|-----------------------------|
| **Пристрій / модель** | **Infinity‑Box** – універсальний програматор/медіа‑тул для Android‑пристроїв. У темі згадуються різні «пакети ПЗ» (версії) для двох основних конфігурацій: <br>• **CM2MT2** – підтримка MediaTek‑SoC (MT6739, MT6761, MT6763, MT6765, MT6768, MT6781, MT6785, MT6833, MT6877, MT6893 тощо). <br>• **CM2SP3** – розширений набір, > 650 моделей, включаючи пристрої на різних SoC (MediaTek, Qualcomm, ін.). |
| **Симптом / несправність** | У темі немає конкретного «зламу» пристрою. Описуються **проблеми, які виникають під час роботи ПЗ** (наприклад, помилка 0x0c000007b, несумісність образу прошивки, помилки читання/запису) та **необхідність оновлення** для підтримки нових моделей/протоколів. |
| **Діагностика** | Не наведено вимірювань чи тестових даних. Є лише опис виявлених помилок ПЗ (наприклад, «пошкоджена інсталяція libusb», «невірний розмір розділу», «неправильне визначення пристрою у Flash‑reader»). |
| **Коди помилок** | - **0x0c000007b** – пов’язаний з пошкодженою інсталяцією `libusb` (виправлено у v2.45). <br> - Інші коди не вказані, проте згадується «помилка зміни розміру графічного інтерфейсу», «помилка підтвердження несумісного образу» тощо. |
| **Деталі та аналоги** | **Вимоги до мікропрограми донгла** (фірм‑чипа, що підключається до ПК): <br>• Для CM2MT2 v2.44‑v2.47 – **dongle 0155** (v2.44‑v2.46) або **dongle 0156** (v2.47). <br>• Для CM2MT2 v2.82 – **dongle 0165**. <br><br>**Підтримувані процесори / пристрої** (неповний список): <br>• MediaTek: MT6739, MT6755, MT6761, MT6763, MT6765, MT6768, MT6771, MT6779, MT6781, MT6785, MT6833, MT6853, MT6873, MT6877, MT6885, MT6893, MT6983 тощо. <br>• Пристрої від: Infinix, Tecno, Vivo, Oppo, Realme, Xiaomi, Samsung, LG, TCL, Beeline, Beista, etc. <br><br>**Нові/оновлені функції** (за версіями): <br>• Показ розміру розділу під час читання/запису. <br>• Режим BROM/FireFly/FireFly DA, RAPHAEL, PRELOADER без Test‑Point. <br>• MemoryTool з синхронізацією масового зчитування/запису, нові повідомлення/помилки. <br>• Автоматичне визначення пристроїв у Flash‑reader. <br>• Підтримка протоколу UltraFlash, SCAT‑loader, META/SVC, LK, RPMB, etc. <br>• Оновлені UI‑елементи, автозбереження профілів, можливість вибору/виключення окремих записів у резервному копіюванні. |
| **Покроковий ремонт (оновлення ПЗ)** | 1. **Перевірити версію донгла** (використовуючи інструмент `DongleInfo` або подібний). <br>2. **Завантажити потрібну версію Infinity‑Box** (наприклад, v2.47 → потребує dongle 0156; v2.82 → потребує dongle 0165). <br>3. **Встановити/оновити драйвери** (у v2.45 виправлено проблему з `libusb`). <br>4. **Розпакувати ПЗ** – зовнішні DLL переміщено у каталог `/lib/`. <br>5. **Запустити Infinity‑Box** – при першому запуску програма автоматично перевірить наявність оновлень (один раз на день). <br>6. **У разі помилки 0x0c000007b** – переінсталювати `libusb` або скористатися вбудованою обробкою зовнішньої DLL (v2.45). <br>7. **Для захищених пристроїв** у режимі PRELOADER підготувати власний Preloader DA або використати пакет `MT2` (містить захищені PRELOADER DA для Tecno, Infinix, Vivo). <br>8. **Після успішного оновлення** – перевірити роботу: <br> • Читання/запис флеш‑пам’яті (розмір розділу, SCAT‑loader). <br> • Роботу MemoryTool (масове зчитування, Scan Filesystem). <br> • Функції розблокування Bootloader, RPMB, тощо. |
| **Результат** | У темі **не вказано остаточного вирішення** конкретної проблеми користувача. Описані лише виправлення та нові можливості у випусках ПЗ. Тому: **не вирішено в темі**. |
| **Застереження / нюанси** | - **Версія донгла має відповідати ПЗ** (0155 → v2.44‑v2.46, 0156 → v2.47, 0165 → v2.82). Невідповідність призводить до помилок підключення та запису. <br>- Для **захищених пристроїв** у режимі PRELOADER потрібен **DA виробника**; без нього програматор не зможе записати прошивку. <br>- У v2.45 виправлено проблему з `libusb`; користувачі старих інсталяцій можуть отримати помилку 0x0c000007b. <br>- Деякі функції (наприклад, автоматичне визначення пристроїв у Flash‑reader) працюють лише на **підтримуваних SoC**; на нових/неперевірених моделях може знадобитися ручний вибір. <br>- При використанні **MemoryTool** слід уважно стежити за вільним місцем на диску – нові версії оптимізують використання, проте надмірне резервування може призвести до збоїв. <br>- **Оновлення UI** та нові підказки можуть змінювати порядок кроків; користувачам варто ознайомитися з новими повідомленнями, щоб уникнути помилок під час процесу прошивки. |

> **Примітка:** У темі не наведено конкретних вимірювань, діагностичних даних чи реальних випадків «поломки» пристрою, тому розділи *Діагностика* та *Що робили по черзі* залишаються без конкретних прикладів. Описані лише загальні кроки оновлення та вимоги, що можна вважати «покроковим ремонтом» у контексті програмного забезпечення Infinity‑Box.
