### 2. Пристрій : **Samsung Galaxy A920F** (SM‑A920F) – єдиний випадок, де описано симптом і план дій

| Пункт | Інформація |
|------|------------|
| **Пристрій / модель** | Samsung Galaxy **A920F** (SM‑A920F) |
| **Симптом / несправність** | Після перерваної прошивки (вимкнення живлення) телефон **не вмикається**, не розпізнається ПК у звичайному режимі. При замиканні **test‑point** на платі пристрій виявляється в режимі **EDL (9008)**. |
| **Діагностика** | – Підключення до ПК у режимі 9008 (QFIL). <br>– Перевірка, чи розпізнається пристрій як Qualcomm 9008 (зазвичай «Qualcomm HS‑USB QDLoader 9008»). <br>– Наявність запиту на **Firehose**‑файл для SM‑A920F. |
| **Коди помилок** | Не зазначено. |
| **Деталі та аналоги** | Запитуваний файл – **Firehose Loader** (програма `prog_emmc_firehose_… .mbn`). У темі немає готового файлу для SM‑A920F, лише прохання його надати. |
| **Покроковий ремонт** (запропонований користувачем) | 1. **Знайти/отримати** відповідний Firehose‑loader для SM‑A920F. <br>2. Підключити телефон у режимі **EDL (9008)** через test‑point. <br>3. Запустити **QFIL** (Qualcomm Flash Image Loader). <br>4. Вибрати завантажений Firehose‑файл. <br>5. Пройти процес **завантаження (download)** прошивки (наприклад, stock firmware у форматі `prog_emmc_firehose`). <br>6. Після успішного завершення – перезапустити пристрій, перевірити завантаження Android. |
| **Результат** | **не вирішено в темі** – файл не був наданий, жодних повідомлень про успішне завершення процесу не з’явилось. |
| **Застереження / нюанси** | - **⚠️ потребує перевірки**: використання неправильного Firehose‑loader (наприклад, для іншого чипа/модельного ряду) може пошкодити eMMC/UFS. <br>- При роботі з test‑point необхідно точно знати розташування контакту (зазвичай TP 1 – TP 2) і уникати короткого замикання інших ліній. <br>- Після успішного завантаження необхідно прошити **повний stock firmware** (завантажувач, boot, system) – інакше телефон може залишитися у “bootloop”. |
| **Примітка** | У темі немає жодних відповідей з готовим файлом, а також немає підтверджень, що інші користувачі успішно використали подібний loader для A920F. |
