**Пристрій / модель**  
- **Realme C55** (кодове ім’я — RMX3710)  
- Чипсет **MediaTek MT6768** (Helio G99)  

**Симптом / несправність**  
- Блокування мережі (SIM‑lock). Телефон приймає SIM‑картку лише від оператора, на який він був проданий, і відмовляє у підключенні інших операторів.

**Діагностика**  
- Визначено, що телефон має мережевий блок. Не проводилось вимірювань апаратних параметрів, а лише виявлено програмну блокування SIM‑картки.  

**Коди помилок**  
- У темі не зазначено жодних кодів помилок.

**Деталі та аналоги**  
| Елемент | Призначення / коментар |
|---------|------------------------|
| `MT6768_Android_scatter.txt` | Scatter‑файл для SP FlashTool, описує розташування пам’яті пристрою. |
| `oplusreserve1.img` | Файл резервної пам’яті (preloader), необхідний для розблокування. |
| **Download Agent** | `mtk_allinone_da` – правильний DA для даної моделі. |
| **SLA / DAA Auth File** | Файл автентифікації, потрібний для успішного запису пам’яті (⚠️ не надано в темі, треба знайти окремо). |
| **Програмне забезпечення** | *SP FlashTool*, *CM2MT2* (або інші MTK‑програматори). |
| **Додаткові інструменти** | *unlocktool* (використано користувачем для успішного розблокування). |
| **Драйвери** | `Oppo-USB-Driver-Setup-V3.1.9.1.zip` – USB‑драйвери для підключення телефону до ПК (проблеми з драйверами на Windows 7 64‑біт). |

**Покроковий ремонт**  

1. **Підготовка ПК**  
   - Встановити USB‑драйвери Oppo (файл `Oppo-USB-Driver-Setup-V3.1.9.1.zip`).  
   - Переконатися, що драйвери працюють (при підключенні телефон має з’явитися в “Device Manager”).  

2. **Підготовка файлів**  
   - Розпакувати архів з `MT6768_Android_scatter.txt` і `oplusreserve1.img`.  
   - За потреби підготувати `SLA/DAA Auth File` (не вказано в темі, його треба отримати окремо).  

3. **Запуск програмного забезпечення**  
   - Відкрити **SP FlashTool** (або CM2MT2).  
   - У полі *Scatter-loading* вибрати `MT6768_Android_scatter.txt`.  

4. **Налаштування параметрів**  
   - У вікні *Download* включити галочку **Preloader** (додати `oplusreserve1.img`).  
   - У полі *Download Agent* вибрати **mtk_allinone_da**.  
   - Натиснути **Ctrl + Alt + V**, перейти на вкладку *Windows* і поставити галочку **Write Memory**.  
   - Додати **SLA / DAA Auth File**, якщо він є.  

5. **Підключення пристрою**  
   - Вимкнути телефон, натиснути і утримувати кнопку **Volume Down** (режим “Download”).  
   - Підключити телефон до ПК через USB.  

6. **Флешування**  
   - У SP FlashTool натиснути **Download** і дочекатися завершення процесу (повідомлення “Download OK”).  

7. **Перезавантаження**  
   - Від’єднати телефон, увімкнути його звичайно.  

8. **Перевірка**  
   - Вставити SIM‑карту будь‑якого оператора.  
   - Переконатися, що мережа розпізнається і телефон працює без блокування.  

**Результат**  
- Користувачі, які виконали описані кроки (зокрема `kvitka0812` та `slavaiam`), повідомляють про успішне розблокування мережі: телефон працює з будь‑яким оператором, без необхідності купувати платні послуги.  

**Застереження / нюанси**  

| № | Опис |
|---|------|
| 1 | **Правильний Download Agent** – використання іншого DA (наприклад, `mtk_da`) призведе до помилки запису. |
| 2 | **SLA / DAA Auth File** – без цього файлу флеш може завершитися помилкою “Authentication failed”. Потрібно знайти його окремо (⚠️ не надано в темі). |
| 3 | **Драйвери** – на Windows 7 64‑біт часто виникають проблеми з встановленням Oppo‑драйверів; у такому випадку рекомендується оновити ОС до Windows 10/11 або використати драйвери для Windows 10 у режимі сумісності. |
| 4 | **Ризик браку** – неправильне вибірання Preloader або вимкнення галочки *Write Memory* може залишити телефон у стані “brick”. Перед початком робіть резервну копію (наприклад, збережіть поточний firmware). |
| 5 | **Вимкнення захисту** – деякі моделі можуть мати захист “Secure Boot”. Якщо після флешу телефон не завантажується, можливо, треба вимкнути Secure Boot у режимі Fastboot (не розглянуто в темі). |
| 6 | **Використання інших програм** – `CM2MT2` або `unlocktool` можуть виконати ту ж операцію без потреби у файлі `oplusreserve1.img`, проте їхня успішність залежить від конкретної прошивки. |
