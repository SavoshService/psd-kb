**Пристрій / модель:** EcoFlow Delta 3 PRO

**Симптом / несправність:** 
- Відсутність реакції на зарядку AC (220В).
- Після заміни плавкого вимикача станція реагує, але реле байпаса та моста циклічно включаються/вимикаються (1 сек увімкнено, потім 20-30 с відключено).
- Дисплей може показувати помилку 304.
- Інші випадки: помилка 111, занижені показники потужності при вимірюванні (наприклад, 1.5 кВт показує як 970 Вт).

**Діагностика:** 
- Перевірка мосфетів — в нормі.
- Заміна драйверів (UCC23513BDWYR) — без ефекту.
- Заміна токомерок — без ефекту.
- Перевірка діодного моста та резисторів плавного старту (200 Ом) — цілі.
- Вимірювання напруги на виході моста: коливається 290В → 200В при спрацюванні реле.
- Перевірка опору по лініях живлення плати керування: норма 650-700 Ом (3,3В), 3.15-2 кОм (5В). У несправних одиницях спостерігається просадка до 300-400 Ом або 200 Ом по 5В.
- Перевірка плати керування: виявлено вигорів процесора (4 Ом по живленню 3,3В) та CAN-контролера.

**Коди помилок:** 
- Помилка 304 (вигорів проц).
- Помилка 111 (занижені показники).

**Деталі та аналоги:** 
- Драйвери: UCC23513BDWYR, UC27624.
- Порівняння токомерок (шунти): норма опору 650-700 Ом (3,3В), 3.15-2 кОм (5В).
- Компоненти плати керування: LM393, TP2412 ⚠️ потребує перевірки (можлива плутанина в назві), NIS1311D.

**Покроковий ремонт:** 
1. Заміна плавкого вимикача 20А.
2. Перевірка/заміна діодного моста.
3. Заміна резисторів плавного старту (200 Ом).
4. Заміна драйверів UCC23513BDWYR.
5. Заміна токомерок.
6. Ізоляція конектора XT-30 для перевірки живлення плати керування (МПРП).
7. Заміна мікрух на платі керування інвертора (TP2412, LM393).

**Результат:** 
Для основного запиту — не вирішено в темі. У інших випадках досягнуто часткового успіху (зарядка працює, але показники занижені) або виявлено критичні пошкодження плати керування (процесор).

**Застереження / нюанси:** 
- Обережно з зворотньою напругою при роз'єднанні конекторів.
- Перевіряти опір токомерок порівняно з робочою станцією (норма 650-700 Ом по 3,3В).
- Вигорів процесора може бути причиною помилки 304 та відсутності індикації.
- Назви компонентів типу TP2412 ⚠️ потребує перевірки (можлива плутанина в назві).
