**Пристрій / модель:** Bluetti AC200P (основна тема), згадки про AC200MAX (аналог/схожа платформа).

**Симптом / несправність:** 
- Невірне відображення напруги батареї на екрані.
- Зарядка зупиняється при 100% або показує скачки (95% → 0%).
- Прилад вимагає зарядку, але не тримає заряд (згідно з іншими дописами про AC200MAX).

**Діагностика:** 
- Вимірювання напруги на батареї мультиметром: **50.7В** (загальна), що відповідає ~3.17В по комірках.
- Показання екрану пристрою: **56.3В**.
- Різниця між реальним значенням та відображеним є суттєвою (~5.6В).

**Коди помилок:** 
- У темі не зазначено.

**Деталі та аналоги:** 
- Плата BMS (Battery Management System).
- МК (мікроконтролер) на платі BMS — об'єкт для заміни з донора.
- Згадка про можливість оновлення прошивки BMS штатними засобами.

**Покроковий ремонт:** 
1. **Вимірювання:** Підтвердження розбіжності між реальним напругою (50.7В) та показаннями (56.3В).
2. **Спроба калібрування/відновлення:** Розрядка станції до 0В, зарядка через роз'єм для сонячних панелей (спроба volodimirk).
3. **Заміна компонентів:** Заміна МК у платі BMS з донора (Jael.Dace, застосовано на AC200MAX).

**Результат:** 
- Для моделі **AC200P**: **не вирішено в темі** (пристрій видали без ремонту).
- Для моделі **AC200MAX**: Заміна МК у платі BMS з донора допомогла.

**Застереження / нюанси:** 
- ⚠️ Потребує перевірки: Метод розрядки/зарядки через сонячні панелі не спрацював у всіх випадках (Jael.Dace).
- ⚠️ Потребує перевірки: Заміна МК BMS має бути з донора тієї ж моделі або сумісної платформи, оскільки рішення для AC200MAX може не підійти до AC200P.
- Важливо використовувати латиницю при записі назв моделей (AC200P/AC200MAX) для пошуку інформації в інтернеті та на форумах.
