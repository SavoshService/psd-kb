**Пристрій / модель:** EcoFlow Delta 3 PRO

**Симптом / несправність:** 
- Відображення помилки **ERROR 117**.
- Відсутність зарядки з розетки (AC).
- Пристрій працює в режимі байпасу ("йде байпас").
- Реле клацають при запуску.
- Вихідна напруга 220В є, навантаження тримає.
- Зарядка від сонячного роз'єма працює нормально.

**Діагностика:** 
- Перепрошивка мікросхем DC/DC U18 та U23 (результату немає).
- Візуальна перевірка транзисторів, резисторів (по 200 Ом), моста діодного — цілі.
- Перевірка реле з випаюванням (desoldered).
- ⚠️ Вимір супротиву по датчику струму на лінії 5В: спостерігається просадка до 200 Ом замість КОм (згадано в контексті помилки 111, але фіксується в темі).
- Перевірка стану LED індикації на модулі DC/DC (зазвичай горить при несправності).

**Коди помилок:** 
- **ERROR CODE 117**: inverter soft start failed (Сбой функции плавного пуска инвертора).
- **ERROR CODE 111**: System Power Fault (загальна несправність системи живлення, перевантаження, перегрів або збій плати інвертора/зарядки) — інформація в темі стосується інших випадків.

**Деталі та аналоги:** 
- **Реле**: Замінено на нове (маркування не зазначено, але заміна виконана).
- **Мікросхеми DC/DC модуля**: TP181A3-CR 9A3 (частіше маркується як 9A3MN). 
- ⚠️ **Нюанс з мікросхемами**: TP181A3-CR є підсилювачем сигналу резистивного датчика струму, а не самим датчиком струму.

**Покроковий ремонт:** 
1. Перепрошивка прошивки DC/DC U18 та U23 через додаток (результат відсутній).
2. Перевірка електронних компонентів (транзистори, резистори, діоди) — цілі.
3. Демонтаж реле для перевірки контактів з випаюванням.
4. Виявлено на одному з реле відсутність одного контакту всередині.
5. Заміна дефектного реле на нове.

**Результат:** 
- Після заміни реле зарядка від розетки відновилася ("зарядка є").
- Пристрій працює в режимі інвертора (не байпас).

**Застереження / нюанси:** 
- Помилка 117 специфічно вказує на збій плавного пуска інвертора, а не просто відсутність живлення.
- Реле можуть видавати звук клацання, але мати внутрішній дефект контакту (не працюють як реле).
- При несправності модуля DC/DC часто горить світлодіод на самій платі ("в полнакала горить світлодіод").
- ⚠️ Дані про вимір супротиву датчика струму стосуються помилки 111, а не 117, але можуть бути корисними для діагностики інших проблем живлення.
- Перепрошивка плати DC/DC (U18/U23) у цьому випадку не допомогла усунути проблему.
