**Пристрій / модель:** EcoFlow DeltaMax 1600

**Симптом / несправність:** 
- При підключенні до мережі станція працює лише кілька секунд, потім спрацьовує захист "оверлоуд" (overload).
- Ток зарядки не регулюється через додаток (споживання з розетки перевищує встановлене обмеження).
- Станція розряджається від батареї нормально.
- MPPT-плата заряджає батарею від постійного струму без проблем.

**Діагностика:** 
- Перевірка роботи плати інвертора без батареї (від мережі працює).
- Перевірка роботи MPPT від постійного струму (заряджає батарею).
- Перевірка резисторів на 2.2 Ом (цілі, звоняться по 2.2 Ом).
- Визначення схеми регулювання струму: обговорено мікрохему струмоміра (вихід 2.5В без навантаження), уточнено, що у DeltaMax 1600 інша схема (маленька 6-лапка на платі процесора).

**Коди помилок:** Оверлоуд (overload) при спробі зарядки від мережі.

**Деталі та аналоги:** 
- Замінено: 4 транзистори синхронної частини, діодний мост, 4 драйвера, резистор R110 (5 Вт).
- Ключова деталь для вирішення проблеми: компонент "9A3" (6-лапка на платі процесора/інвертора).

**Покроковий ремонт:** 
1. Заміна згорілих компонентів після удару високовольтним струмом (мосфети, драйвери, мост, R110).
2. Перевірка роботи плати інвертора без батареї.
3. Перевірка роботи MPPT.
4. Перевірка резисторів на 2.2 Ом.
5. Заміна компонента "9A3" (6-лапка).

**Результат:** Станція запрацювала після заміни компонента "9A3".

**Застереження / нюанси:** 
⚠️ потребує перевірки: Номінал резистора R110 не видно, замінено на 380 Ом по фото з інтернету (для потужного пристрою це може бути підозріло).
⚠️ потребує перевірки: Уточнено, що мікрохема струмоміра з виходом 2.5В без навантаження не підходить для DeltaMax 1600, там інша деталь.
