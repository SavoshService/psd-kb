**Пристрій / модель**  
- Infinix Note 30 Pro NFC, модель **X678B** (проект `x678b_h894`, платформа **MT6789**).  

**Симптом / несправність**  
- У першій частині симптоми не вказані – користувач просто виконував чисту прошивку.  
- У другій частині користувач хоче отримати оригінальний `boot.img` (для подальшого root‑ування Magisk) та повну резервну копію заводської прошивки. Технічних проблем з пристроєм не зазначено.  

**Діагностика**  
- Підключення до режиму **BOOTROM** через InfinityBox v2.52 (COM27).  
- Логи підключення:  

  ```
  CHIP MT6789 SBID 0x8A00 HWVR 0xCA00 SWVR 0x0000 EVOL 0x0000 HWC 0x1208
  CODE G99, TYPE NEXTGEN [LUCI]
  MEID ACD696B8A881D29F5272B6FDFBB1F88D (пізніше 068E298B96441BCCF183A382A3DDCAC9)
  BROM Sec Level 0x000000E5 Mode SBC+SDA+EXT, VER 0x05 BL 0xFE
  Auth accepted (auth_sv5.auth), SLA Challenge Pass
  ```  

- Перевірка розділів: **Checksum Verify** – не успішно.  
- Попередження під час прошивки:  

  - `Scat|PMT: number of partitions mismatch`  
  - `Warning: DEVICE <-> FIRMWARE PartTable mismatch! Continue may destroy device security!`  

- Параметри апаратури під час прошивки (записані InfinityBox):  

  | Параметр | Значення |
  |----------|----------|
  | Пам’ять UFS | `eUFS2.2_256` |
  | LUN0 | 4 MB |
  | LUN1 | 4 MB |
  | LUN2 | 238.71 GB |
  | LUN3 | 0 B |
  | RAM (після ініціалізації) | 8 GB (0x0200000000) |
  | Батарея | 4358 mV → 4362 mV |
  | ID‑пам’яті | H9HQ15AFAMBDAR 8 GB, KM2P9001CM‑B518 6 GB, KM8F9001JM‑B813 8 GB, H9QT1G6DN6X132 8 GB, H9QT0G6CN6X146 8 GB |

**Коди помилок**  
- `CODE G99` – типово для MT6789 у режимі BOOTROM.  
- Попередження про **mismatch** таблиці розділів (не критичні, але вимагають підтвердження користувачем).  

**Деталі та аналоги**  
- **ROM‑и, які згадуються:**  

  | ROM | Опис |
  |-----|------|
  | EU 1 | `X678B‑H894Q‑T‑EU‑230426V1043` (Factory Signed) |
  | EU 2 | `X678B‑H894Q‑T‑EU‑231009V2642` |
  | OP   | `X678B‑H894OPQ‑T‑OP‑240108V3414` |
  | RU   | `X678B‑H894Q‑T‑RU‑240105V3395` |

- **Файли прошивки (розмір, SHA‑1)** – повний список у темі (від `vbmeta.img` до `super.img` ≈ 5.57 GB).  
- **Інструменти:** InfinityBox v2.52, Pandora (для бекапу), Halabtech (джерело “офіційної” прошивки).  
- **Аналоги/донори:** інші X678B‑H894* прошивки (OP, RU) можуть бути використані, проте у темі обговорювали лише EU‑версії.  

**Покроковий ремонт (процедура прошивки)**  

1. **Підготовка**  
   - Вимкнути телефон, зачекати ≈ 20 сек.  
   - Під’єднати USB‑кабель, утримуючи **Vol+ | Vol‑** (режим BOOTROM).  

2. **Підключення InfinityBox**  
   - Дочекатися підключення (COM27, режим BOOTROM).  
   - Перевірити лог – має з’явитися `CODE G99`.  

3. **Вибір прошивки**  
   - Завантажити потрібний образ (наприклад `X678B‑H894Q‑T‑EU‑230426V1043`).  

4. **Розділення та підготовка**  
   - `Re‑Partition` – OK.  
   - `Checksum Verify` – **не успішно** (примітка, але процес продовжується).  

5. **Попередження**  
   - Поява повідомлення `Scat|PMT: number of partitions mismatch`.  
   - Поява `Warning: DEVICE <-> FIRMWARE PartTable mismatch! Continue may destroy device security!` → користувач підтверджує “Yes”.  

6. **Стерт і запис**  
   - `FLASH ERASE` – виконано (кілька ділянок).  
   - Запис усіх розділів (`VBMETA`, `MD1IMG`, …, `USERDATA`) – **OK**.  

7. **Повторне розділення**  
   - `Re‑Partition` – OK (другий раз).  

8. **Завершення**  
   - Після успішного запису – повідомлення `Done: 00:09:59`.  
   - Рекомендація: перепідключити живлення/кабель.  

9. **Перевірка**  
   - У темі лише зазначено «фото‑доказ», без детального опису результату.  

**Результат**  
- **Частина 1:** Прошивка завершилась без критичних помилок; користувач навів фото‑доказ успішної прошивки, проте детальний опис стану пристрою після процесу відсутній.  
- **Частина 2:** Користувач не отримав потрібного `boot.img`/Factory Signed Firmware; відповідь надала лише рекомендації щодо бекапу (Pandora) та посилання на “халяву” з Halabtech, без фактичного надання файлів. **Результат – не вирішено в темі**.  

**Застереження / нюанси**  

- **Попередження про розбіжність таблиці розділів** – продовжувати лише якщо впевнені, що прошивка відповідає саме вашій моделі (X678B‑H894Q). Інакше можлива втрата даних або блокування безпеки.  
- **Checksum Verify** не пройшов – це може вказувати на пошкоджений образ або несумісність; у темі процес все ж був продовжений, проте ризик існує.  
- **Обов’язковий бекап** перед будь‑якими змінами (рекомендовано Pandora). Без бекапу неможливо відновити оригінальний `boot.img`, якщо щось піде не так.  
- **Використання сторонніх джерел (Halabtech)** – файли не гарантуються офіційними, можуть містити модифікації або бути несумісними.  
- **Після прошивки** варто перевірити:  
  - Чи працює NFC (модель має NFC).  
  - Чи коректно розпізнаються UFS‑модулі (вказані ID‑пам’яті).  
  - Чи не з’явилися нові коди помилок у логах BOOTROM.  
- Якщо потрібен **оригінальний `boot.img`** для Magisk, найпростіший шлях – створити його з поточної заводської прошивки за допомогою Pandora (або інструменту `fastboot bootimg dump`). У темі це не було реалізовано.
