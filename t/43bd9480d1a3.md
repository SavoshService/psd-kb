**Пристрій / модель:**  
- Ноутбук **Asus FX506** (модельна плата **DABKXDMB8F0**).

**Симптом / несправність:**  
- Після залиття водою **не працює третя фаза живлення GPU** (GPU PWM3).  
- При підключенні мережевого блоку (БЖ) **перша і друга фази (PL12 + PQ44, PL13 + PQ45) швидко перегріваються** (температура, що «попікає» пальці).  
- Третя фаза **перестає працювати** – на лінії **GPU_PWM3** замість ШІМ‑сигналу постійний **високий рівень**.  
- При відключенні БЖ третя фаза не активується, її треба «перезапустити» через заряд батареї.  
- Акумулятор справний, усі три фази живлення в цілому працюють, лише третя не вмикається.

**Діагностика:**  
| Елемент | Дії / спостереження | Примітки |
|---|---|---|
| ШІМ‑чіп **MP2884A (PU14)** | Не піднімав (планував підняти наступного дня). | Програмований, має прошивку. |
| Драйвер третьої фази **PU17 MP8693** | На лінії **GPU_PWM3** постійний високий рівень (відсутність PWM‑модуляції). | |
| Транзистори **PQ44, PQ45, PQ46 (QA3118M6N)** | PQ44 (перша фаза) вже мінявся попередниками. Окислення під транзисторами. | |
| Дроселі **PL12, PL13, PL14** | PL14 поміняв місцями з PL12; під ними виявлено окислення. | |
| Дільник **PR279 (VINSEN)** | Після всіх замін та чистки виявився причиною. | |
| Візуальний огляд | Окислення на дроселях, транзисторах, дільнику. | |
| Тестування після замін | Після підняття (запуску) ШІМ‑чіпу та заміни/перестановки елементів – проблема залишалась до виявлення PR279. | |

**Коди помилок:**  
- В темі не вказано жодних кодів помилок BIOS/EC.

**Покроковий ремонт:**  
1. **Візуальний огляд** – виявлено окислення під дроселями PL12/PL13/PL14, транзисторами PQ44‑PQ46, а також під дільником PR279.  
2. **Перестановка індуктивностей** – PL14 поміняв місцями з PL12 (для діагностики).  
3. **Перестановка транзисторів** – PQ46 перемістив, щоб перевірити, чи «перегорить» інша фаза.  
4. **Чистка** – усі окислені ділянки очищено (механічно, із застосуванням ізопропілового спирту).  
5. **Підйом (програмування) ШІМ‑чіпу MP2884A** – планувалося, але виконано лише після виявлення PR279.  
6. **Заміну/перестановку елементів** – деякі MOSFET та дроселі замінено/переставлено, проте проблема залишалась.  
7. **Діагностика PR279** – після вимірювання напруги на виводах дільника виявлено відхилення (відсутність потрібної опорної напруги).  
8. **Заміну PR279** – встановлено новий дільник VINSEN.  
9. **Перевірка роботи** – після заміни PR279 PWM‑лінія GPU_PWM3 відновила PWM‑модуляцію, третя фаза GPU почала працювати, перегрів першої і другої фаз припинився.  

**Результат:**  
- **Проблема вирішена** – третя фаза живлення GPU працює коректно після заміни дільника **PR279**.  
- Перша і друга фази більше не перегріваються.  
- Не було потреби у заміні ШІМ‑чіпу MP2884A, хоча його підняли (програмування) під час фінального етапу.

**Застереження / нюанси:**  
- **Вода = корозія.** Після залиття слід ретельно очистити всі контакти, пайки та компоненти (ізопропіл, анти‑статичний інструмент).  
- **Програмований ШІМ‑чіп** потребує спеціального програматора; без нього діагностика може бути ускладнена.  
- **Перегрів MOSFET‑транзисторів** – навіть якщо температура «в межах норми», постійний високий рівень на PWM‑лінії може швидко привести до їх виходу з ладу.  
- **Дільники напруги** (наприклад PR279) часто залишаються «невидимими» під час швидкої діагностики, проте їх пошкодження призводить до відсутності PWM‑сигналу.  
- При заміні індуктивностей та транзисторів важливо зберігати їх **правильну полярність та позицію** (записати схему перед перестановкою).  
- Після ремонту **рекомендовано провести повний тест навантаження** (GPU stress‑test) для підтвердження стабільності всіх трьох фаз.
