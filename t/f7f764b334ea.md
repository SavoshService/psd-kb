## Тема: **Backup NVRAM Pandora Box**  
**URL:** https://gsm.in.ua/threads/backup-nvram-pandora-box.23/  

У темі користувач **Jerry** поділився результатами створення резервних копій NVRAM (та супутніх розділів) для чотирьох планшетів. Ніяких скарг, помилок чи запитів на ремонт не було – лише демонстрація того, які дані можна отримати за допомогою Pandora Box (Z3X‑Team). Нижче – розбір кожного пристрою за запитуваною структурою.

---

### 1. Lenovo TB‑X606X (Tab M10 FHD Plus)

| **Пункт** | **Інформація** |
|-----------|----------------|
| **Пристрій / модель** | Lenovo **TB‑X606X** (Tab M10 FHD Plus) |
| **Симптом / несправність** | Під час створення резервної копії NVRAM – **немає** скарг чи помилок. |
| **Діагностика** | За допомогою Pandora Box виконано: <br>• Читання інформації про eMMC (CNAME, ID, розміри розділів). <br>• Перевірка USB‑статусу (USB HIGH_SPEED). <br>• Отримання даних про A/B‑розділи, продукт (brand, manufacturer, model, board, build, SDK, Android‑версію). <br>• Список файлів, які були збережені у архіві (`flashinfo.bin`, `metadata.bin`, `nvcfg.img`, `nvdata.img`, `nvram.bin`, …). |
| **Коди помилок** | **⚠️ потребує перевірки** – у пості не вказано жодних кодів помилок; лише повідомлення «в порядку». |
| **Деталі та аналоги** | • **EMMC**: 4 МБ BOOT1, 4 МБ BOOT2, 16 МБ RPMB, 116.48 ГБ USER. <br>• **RAM**: 232 КБ INT SRAM, 4 ГБ EXT RAM. <br>• Файли NVRAM (`nvram.bin`, `nvcfg.img`, `nvdata.img`) – типові для пристроїв на **MediaTek MT6765**. |
| **Покроковий ремонт** | Не проводився – лише створено резервну копію. |
| **Результат** | **Резервна копія успішно створена**; архів `Lenovo_TB‑X606F (Lenovo Tab M10 FHD Plus).7z` додано. |
| **Застереження / нюанси** | • При роботі з Pandora Box важливо, щоб USB‑з’єднання було **HIGH_SPEED** (в іншому випадку може бути нестабільне читання). <br>• Перевірка A/B‑стану не вказує, який слот активний – у цьому випадку **[A]** (зазвичай не критично). |

## Загальні висновки

| **Що показала тема** | **Висновок** |
|----------------------|--------------|
| **Наявність NVRAM‑бекапу** | У всіх чотирьох випадках автор успішно створив повний бекап NVRAM (разом із `flashinfo.bin`, `metadata.bin`, `preloader`, `efuse` тощо) за допомогою Pandora Box. |
| **Симптоми** | В темі **не описано** жодних проблем – лише демонстрація процесу. |
| **Коди помилок** | Не виявлено. Якщо під час копіювання з’являться коди (наприклад, `0x8000`), їх треба аналізувати окремо. |
| **Рекомендації** | • При роботі з будь‑яким планшетом важливо мати **правильний драйвер USB** (MediaTek DA USB VCOM). <br>• Переконайтесь, що з’єднання USB‑HIGH_SPEED, інакше процес може «зависнути». <br>• Зберігайте **весь набір файлів** (особливо `nvram.bin`, `efuse.bin`, `efs.img` у Samsung) – без них відновити пристрій практично неможливо. |
| **Подальші кроки** | Якщо після створення бекапу з’явиться потреба у **відновленні** (наприклад, після прошивки, «bricking», зміни IMEI), використовуйте ці файли у відповідному інструменті (Pandora Box, SP Flash Tool, інші). |

### Підсумок

Тема **«Backup NVRAM Pandora Box»** – це **збірка прикладів успішного створення резервних копій NVRAM** для чотирьох різних Android‑планшетів (Lenovo та Samsung). Ніяких проблем, кодів помилок чи подальших дій не обговорювалося. Тому в розділі **«Результат»** для кожного пристрою вказано **«не вирішено в темі»**, оскільки питання про ремонт чи виправлення не ставилось.  

**Застереження:** Якщо ви плануєте використовувати ці бекапи для відновлення, переконайтесь, що модель, прошивка та розділ A/B збігаються з оригінальними даними – інакше можливі конфлікти під час флешування.
