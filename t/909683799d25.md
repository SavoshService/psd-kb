**Деталі та аналоги**  
- **Новий функціонал Chimera:** додано можливість **скидання облікового запису Mi** (Mi Account) для телефонів Xiaomi з процесором **MTK**. Операція виконується у **режимі bootrom / попереднього завантаження** (pre‑boot), без необхідності завантаження Android‑системи.  
- **Підтримка Qualcomm‑пристроїв:** виправлені помилки сумісності в режимі **EDL** (Emergency Download Mode) для моделей TCL/Alcatel/Nokia (наприклад, Alcatel 1B 5002S/5002H) та розширений набір програмістів для нових Samsung‑моделей (BIT2‑BIT4).  
- **Загальні покращення:** оптимізовано роботу API, щоб уникнути «заповнення» (flooding) запитів; зазначено, що зміни можуть бути несумісними з деякими прошивками.  

**Застереження / нюанси**  
- Функція скидання Mi‑акаунту працює **лише у режимі bootrom**; якщо пристрій не входить у цей режим (наприклад, через захист FRP), процедура може бути недоступною.  
- Підтримка конкретних моделей вказана у списку, проте **можливі варіації прошивки** (BIT‑версії, регіональні модифікації), які можуть вимагати додаткових налаштувань Chimera.  
- Оновлення API може **викликати конфлікти** з існуючими скриптами чи кастомними прошивками; перед застосуванням нових скриптів рекомендується створити резервну копію.  
- Для Qualcomm‑пристроїв у режимі **EDL** підтримка розширена, проте **не гарантується** 100 % успішність на всіх варіантах апаратного забезпечення (наприклад, різні ревізії чипів).
