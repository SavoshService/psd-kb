**Пристрій / модель:** EcoFlow **River Pro Max** (портативна зарядна станція) з додатковою батареєю (доп. батарея‑модуль).

### Симптом / несправність
| Опис | Деталі |
|------|--------|
| **Без додаткової батареї** | Станція вмикається, працює, **зарядка “плаває”**: потужність поступово піднімається до ~270 W, через кілька секунд різко падає до 30‑40 W, потім цикл повторюється. Оновлення прошивки не допомогло. |
| **З додатковою батареєю** | При підключенні швидко блимає діод, через кілька секунд станція вимикається, **на виході BMS напруга не піднімається**. |
| **Додаткові ознаки** | При вимкненій дод. батареї зарядка зупинилася на 88 % і більше не брала струм. При розрядці до 0 % (за індикатором) зарядка перестає працювати, хоча напруга на всіх комірках **≈ 3,67 V**. |

### Діагностика
| Дія | Результат |
|-----|-----------|
| **Від’єднання дод. батареї** | Станція стартує, працює, але спостерігається “плаваюча” зарядка. |
| **Вимірювання напруги комірок** | – Одна комірка (зовнішньої батареї) була **0,26 V** (майже нуль). Після підвищення напруги (заправки) станція не стартувала. <br> – Основна батарея: усі 4‑5 (залежно від конфіг.) комірки **3,67‑3,68 V**. |
| **Спостереження за потужністю** | Під час зарядки: 0 → ~270 W → різке падіння до 30‑40 W → повтор. |
| **Перевірка BMS** | При підключеній дод. батареї швидке блимання діода, відсутність підвищення вихідної напруги. |
| **BMS RESET** (натискання кнопки Reset на BMS) | Після скидання BMS **зарядка відновилася** (хоча індикатор залишався 0 %). |

### Покроковий ремонт (те, що було виконано в темі)
1. **Від’єднати додаткову батарею** – дозволило запустити станцію.  
2. **Виміряти напругу всіх комірок** – виявлено одну “мертву” комірку (0,26 V) у дод. батареї, основна батарея – 3,67‑3,68 V.  
3. **Спробувати підвищити напругу “мертвої” комірки** – без успіху, станція не стартувала.  
4. **Перевірити BMS** – швидке блимання діода, відсутність вихідної напруги.  
5. **Натиснути кнопку BMS RESET** – зарядка відновилася, хоча індикатор залишався 0 %.  
6. **План** – подальше тестування під навантаженням, перевірка зовнішньої батареї, можлива заміна/балансування комірок.

---

### Результат
- **Основна батарея**: після BMS RESET зарядка працює, проте індикатор залишає 0 % (можливий залишковий збій у вимірювачі SOC).  
- **Додаткова батарея**: проблема не вирішена, станція не стартує, швидке блимання діода зберігається.  
- **Загальний висновок**: **часткове вирішення** – основна станція функціонує, але зовнішня батарея, ймовірно, має вм’яту/мертву комірку, що блокує запуск.  

---

### Застереження / нюанси
- **Низька напруга окремої комірки (< 2,5 V)** → BMS автоматично вимикає станцію для захисту. Потрібно або **балансувати/перезарядити** таку комірку, або **замінити** її/весь модуль батареї.  
- **BMS RESET** часто лише тимчасово знімає захист; якщо причина (пошкоджена комірка) не усунута, помилка повернеться.  
- При роботі з Li‑ion **не допускайте глибокого розряду** (нижче 2,5 V) – це скорочує ресурс батареї і викликає подібні “плаваючі” режими зарядки.  
- При підключенні **додаткових батарей** переконайтеся, що їх **напруга та баланс** відповідає вимогам станції; інакше BMS може блокувати запуск.  
- Якщо індикатор SOC застряг на 0 % при реальній напрузі 3,6‑3,7 V, **перепрошивка/калібрування** BMS може знадобитися.
