## Розбір теми «Розблокування FRP Lenovo Tab P12 Pro (TB‑Q706)»

| Пункт | Інформація |
|-------|------------|
| **Пристрій / модель** | **Lenovo Tab P12 Pro** (модель TB‑Q706) |
| **Симптом / несправність** | Блокування **Google Factory Reset Protection (FRP)** – після скидання пристрій вимагає ввести Google‑акаунт, який не відомий користувачу. |
| **Діагностика** | У темі не вказано жодних вимірювань, тестів чи сканувань. |
| **Коди помилок** | Не зазначено. |
| **Деталі та аналоги** | * Програма **QFIL** (Qualcomm Flash Image Loader) – стандартний інструмент для прошивки/розблокування пристроїв на базі Qualcomm.<br>* **Programmer file** – `prog_firehose_ddr_TB-Q706F.elf` (firehose‑драйвер для DDR‑пам’яті конкретної моделі).<br>* **XML‑файл** – `rawprogram_unsparse0.xml` (опис розмітки пам’яті, яку треба записати).<br>* Файли постачаються в архіві `TB-Q706F_FRP.7z`.<br>* Потрібно перевести планшет у режим **EDL** (Emergency Download Mode) – спеціальний режим завантаження, який дозволяє записувати прошивку без завантаження Android. |
| **Покроковий ремонт** | 1. **Завантажити** архів `TB-Q706F_FRP.7z` (7‑zip).<br>2. **Розпакувати** архів, отримати папку *IMAGE* з файлами.<br>3. **Запустити** програму **QFIL**.<br>4. У QFIL **встановити** галочку **Flat Build** (використовується «плоска» (flat) прошивка).<br>5. У полі *Programmer File* вибрати `prog_firehose_ddr_TB-Q706F.elf`.<br>6. Натиснути кнопку **Load XML** і вибрати `rawprogram_unsparse0.xml` з тієї ж папки *IMAGE*.<br>7. **Перевести планшет у режим EDL** (зазвичай за допомогою спеціального кабелю/комбінації кнопок або через ADB‑команду `adb reboot edl`).<br>8. У QFIL натиснути **Download** – програма запише образ у пам’ять пристрою.<br>9. Після завершення процесу планшет автоматично перезавантажиться – **FRP‑блокування знято**. |
| **Результат** | У посту зазначено: *«пару секунд та планшет розблокований»* – тобто автор вважає, що процедура успішно зняла FRP. Офіційного підтвердження (фото, скріншот) у темі немає. |
| **Застереження / нюанси** | - **Режим EDL** – дуже низькорівневий, неправильне використання може **пошкодити** пристрій (brick).<br>- Потрібні **правильні драйвери Qualcomm** (QDLoader) на ПК; без них QFIL не розпізнає пристрій.<br>- Використання даних файлів **може порушувати** умови гарантії та політику Google щодо FRP; користувач несе відповідальність.<br>- Якщо пристрій не входить у режим EDL, треба шукати специфічну **комбінацію кнопок** або **спеціальний тест‑модуль** (наприклад, “deep flash” кабель).<br>- У випадку **помилок під час завантаження** (наприклад, “Failed to download” або “QFIL error 0x…”) треба перевірити USB‑кабель, порт, стабільність живлення та сумісність файлів.<br>- **⚠️ потребує перевірки**: успішність процесу не підтверджена в темі (відсутні скріншоти, відгуки інших користувачів). |
| **Примітка** | Тема містить лише інструкцію – жодних діагностичних даних, вимірювань чи кодів помилок. Тому розбір обмежений саме цим. |
