**Пристрій / модель:** EcoFlow (конкретна модель не вказана).

**Симптом / несправність:** Необхідність перегляду даних про цикли заряду та стан батареї через сторонній додаток (офіційний інтерфейс може бути обмеженим для цієї мети).

**Діагностика:** Підключення до пристрою через звичайну програму від виробника, потім вхід у сторонній додаток за допомогою серійного номера пристрою.

**Коди помилок:** Відсутні.

**Деталі та аналоги:** 
- Формат: APK файл (Android).
- Для iOS: веб-версія через браузерну вкладку.
- Версії програми: 2.8, 2.17.
- Майданчик завантаження: MEGA (доступність змінюється).

**Покроковий ремонт:** 
1. Завантаження APK файлу або відкриття веб-версії.
2. Вхід у додаток за логіном і паролем.
3. Додавання станції по серійнику.
4. Перегляд інформації (цикли заряду тощо).

**Результат:** Додаток дозволяє швидко переглядати комірки та дані, синхронізація з Google акаунтом доступна у версії 2.17.

**Застереження / нюанси:** 
- ⚠️ Посилання на MEGA для завантаження може бути недоступним або видалене (старі версії файлів видалено).
- Для iOS встановлення як додатку без сертифіката розробника неможливе, доступна лише веб-версія.
- ⚠️ Старі версії програми можуть не підтримувати оновлення з 2.8 версії.
