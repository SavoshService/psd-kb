**Пристрій / модель:** Motorola RG248WQ (відомий також як Motorola G9)  

**Симптом / несправність:**  
- Пристрій заблокований графічним (pattern) ключем.  
- При введенні неправильного ключа блокуються спроби, відновлення через Google‑акаунт недоступне (не відома електронна пошта, двофакторна автентифікація).  
- Потрібно зняти блокування **без втрати даних** (користувач помер, дані важливі).

**Діагностика:**  
- Ніяких вимірювань, тестів чи логів у темі не наведено.  
- Є лише констатація, що дані **шифруються** (типово для Android 10/11, які встановлені на G9).  

**Коди помилок:**  
- В темі не згадуються коди помилок або повідомлення системи.

**Деталі та аналоги:**  
- **Шифрування:** При включеному захисті Android‑пристрої (File‑Based Encryption) дані користувача шифруються ключем, який генерується під час першого налаштування і прив’язується до облікового запису Google. Без успішної автентифікації (пароль, PIN, pattern) розшифрувати сховище неможливо.  
- **Інструменти, які згадуються:**  
  - **Cellebrite UFED** – професійний криміналістичний комплект, дозволяє витягнути дані лише після успішного обходу або розблокування пристрою (зазвичай потребує експлойтів, які не завжди доступні для нових прошивок).  
  - **Oxygen Forensic Detective** – подібний інструмент, має модулі для обходу Android‑блокувань, але успішність залежить від конкретної версії ОС та патч‑рівня.  
  - **ADB / Fastboot** – стандартні інструменти розробника, які можуть бути використані лише після розблокування завантажувальника (bootloader) або отримання root‑доступу, що у випадку заблокованого пристрою без розблокування облікового запису неможливо.  
  - **Комерційні програми для «розблокування»** (dr.fone, iMyFone LockWiper, 4ukey) – пропонують «зняття» pattern‑lock, проте у випадку шифрування даних вони лише стирають користувацькі дані (factory reset), а не зберігають їх.  

**Покроковий ремонт:** *(згідно з обговоренням – жодних реальних кроків не виконувалося)*  
1. **Оцінка можливості розблокування через Google:**  
   - Перевірка наявності Google‑акаунту та можливості відновлення пароля – **невдача** (адреса електронної пошти невідома, двофакторна автентифікація).  
2. **Спроба використання сторонніх програм:**  
   - Перераховані програми (dr.fone, iMyFone, 4ukey) – **не випробувані** у темі, лише запит про їх ефективність.  
3. **Звернення до професійних криміналістичних інструментів:**  
   - Згадано Cellebrite UFED та Oxygen Forensic Detective – **не проведено** (користувач зазначив, що в сервісі не вдалося розблокувати).  
4. **Висновок:** без успішної автентифікації Google‑акаунту або без наявності вразливості, що дозволяє обійти шифрування, дані **не підлягають відновленню**. Єдиний гарантований шлях – **повне стирання** (factory reset) з втратою даних.

**Результат:**  
- **Не вирішено в темі.** Жоден з запропонованих методів не привів до успішного зняття графічного ключа без втрати даних.

**Застереження / нюанси:**  
- ⚠️ **Шифрування даних** на Android‑пристроях робить неможливим їх розшифрування без правильного облікового запису або без використання вразливості, яка дозволяє обійти захист.  
- Будь‑які «програми для розблокування» зазвичай **видаляють** користувацькі дані (factory reset) і не зберігають їх. Якщо дані важливі, їх втрата неминуча без доступу до Google‑акаунту.  
- **Cellebrite** та **Oxygen Forensic** – дорогі професійні рішення, які можуть працювати лише за умови, що виробник ще не виправив відповідну вразливість. Для моделей, випущених після 2020 р., успішність дуже низька.  
- **ADB/Fastboot** без розблокованого bootloader'а недоступні; їх спроба без попередньої розблокування призведе лише до повідомлення «device is locked».  
- Якщо є фізичний доступ до SIM‑карти, можна спробувати **використати номер телефону** для відновлення Google‑акаунту (SMS‑код), проте це вимагає доступу до самого акаунту (відомий email/пароль) – у даному випадку недоступно.  
- У випадку, коли дані треба зберегти, **єдиний варіант** – звернутися до **служби розслідування** (поліція, судово‑медична експертиза) з відповідним ордером, яка може мати доступ до спеціалізованих інструментів.
