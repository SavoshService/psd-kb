**Пристрій / модель:**  
EcoFlow (портативна зарядна станція, будь‑яка модель – Delta, River, Bluetti тощо)

**Симптом / несправність:**  
Користувач хоче отримати більш детальну статистику та можливість керування станцією з ПК. На телефоні інформації недостатньо, а офіційного ПЗ для Windows не знайдено.

**Діагностика:**  
*Не проводилась.* У темі лише обговорювали, яким чином можна отримати дані зі станції.

**Коди помилок:**  
Відсутні.

**Деталі та аналоги:**  
- Програма, про яку йдеться, не є готовим GUI‑додатком, а **код**, який запускається у **Docker**‑контейнері.  
- Офіційно підтримується лише **Linux**‑середовище; під Windows необхідно встановити **Docker Desktop** і запускати той самий контейнер.  
- У темі згадується відео‑інструкція (посилання не наведено), яка пояснює налаштування під Windows.

**Покроковий ремонт (налаштування):**  
1. **Встановити Docker Desktop** для Windows (або Docker Engine для Linux).  
2. Завантажити Docker‑образ з кодом моніторингу EcoFlow (посилання в інструкції, зазвичай це репозиторій на GitHub).  
3. Запустити контейнер, передавши необхідні параметри (наприклад, IP‑адресу станції, токен/ключ API).  
4. Увійти у веб‑інтерфейс, який відкривається у браузері (зазвичай за адресою `http://localhost:PORT`).  
5. Переглядати статистику (напруга, струм, залишок заряду, температура тощо).  
6. Керування (вимкнення/ввімкнення виходів) **не передбачено** у цьому коді – лише моніторинг.

**Результат:**  
У темі немає остаточного підтвердження успішного налаштування; користувачі лише отримали інструкції. → **не вирішено в темі**.

**Застереження / нюанси:**  
- Docker‑контейнер працює лише в середовищі, де є підтримка Docker (Linux або Windows 10/11 Pro/Enterprise з включеним WSL 2).  
- Потрібно мати **правильний API‑ключ** або інший спосіб автентифікації, який надає EcoFlow (зазвичай отримується через офіційний мобільний додаток).  
- Керування станцією (ввімкнення/вимкнення портів) у цьому рішенні **не реалізовано** – лише читання даних.  
- При роботі під Windows можлива потреба у налаштуванні **виртуальної мережі** Docker (port forwarding).  
- Якщо Docker Desktop не встановлений або не запущений, контейнер не стартуватиме, і доступу до статистики не буде.
