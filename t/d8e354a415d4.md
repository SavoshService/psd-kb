**Пристрій / модель**  
- Blackview **A96**  
- Blackview **BV6300 Pro**

**Симптом / несправність**  
- На A96 виводиться повідомлення **“Tee key”** (відсутній/невірний keybox).  
- На BV6300 Pro – **“Not verify”** (не пройдено верифікацію bootloader‑a).  

**Діагностика**  
- Ніяких вимірювань (напруга, опір, температури) не проводилось.  
- Перевірка виконувалась лише програмно:  
  1. Спроба прошити **full firmware** з донорської плати – результат без змін.  
  2. Використання **SN‑writer** – не приймає чужі UUID‑ключі.  
  3. Перевірка опції **“write kb keybox tee google infinity”** в Infinity‑Box – потребує файл keybox/UUID, який не знайдено.  

**Коди помилок**  
- “Tee key” – типове повідомлення про відсутність/невірність **keybox** (Google/Qualcomm).  
- “Not verify” – помилка верифікації **bootloader** (зазвичай вимагає правильний **UUID**/keybox).  

**Деталі та аналоги**  
| Поняття | Опис |
|---|---|
| **Keybox / KB** | Зафіксований у пристрої файл, що містить криптографічний ключ (UUID) для розблокування bootloader‑а. |
| **UUID** | Унікальний ідентифікатор (зазвичай 16‑байтовий), який генерує виробник і який потрібен для створення правильного keybox. |
| **Infinity‑Box** | Програматор/модуль для прошивки та запису keybox‑ів у Qualcomm‑пристрої. Працює лише за наявності коректного UUID‑файлу. |
| **SN‑writer** | Програма для запису серійних номерів/UUID у пристрої. Не приймає чужі (не підходять) UUID. |
| **Donor board** | Донора‑плата, з якої береться firmware/partition‑и. Не містить UUID‑файлів, потрібних для конкретного пристрою. |

**Покроковий ремонт (те, що було спробовано)**  
1. **Full flash** з донорської плати → нічого не змінило.  
2. **SN‑writer** → відмова приймати чужі UUID.  
3. Спроба використати **Infinity‑Box** з опцією *write kb keybox tee google infinity* → потребує файл keybox/UUID, який не знайдено.  
4. Запит до **підтримки Blackview** (email support02@blackview.hk) – відповіді не отримано.  

**Результат**  
- **Не вирішено в темі**.  
- Інструмент Infinity‑Box без правильного **UUID** не зможе створити/записати потрібний keybox, отже розблокувати bootloader неможливо.  

**Застереження / нюанси**  
- **⚠️ потребує перевірки**: чи існує можливість отримати UUID без офіційної підтримки (наприклад, через інструменти Qualcomm “qfuse” або інші методи).  
- Використання **чужих UUID** або неправильних keybox‑ів може **запрограмувати пристрій у “brick”** (непридатний до запуску).  
- При роботі з Infinity‑Box необхідно мати **точний файл keybox** (зазвичай у форматі `.bin` або `.txt`), який генерується на підставі UUID. Без нього запису не відбудеться.  
- Якщо виробник не надає UUID, єдиний легітимний шлях – **офіційна підтримка** або **заміна пристрою**.
