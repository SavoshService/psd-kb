**Пристрій / модель:**  
- Meizu Note 2 (марка — Meizu, модель — M2 NOTE, чіп — MT6753)

**Симптом / несправність:**  
- Не вдається «форматувати» (factory reset) телефон.  
- FRP‑інструмент **Octopus FRP Tool** повертає *operation failed*.  
- **UnlockTool** не може переключити пристрій у режим BROM (DA).  
- При спробі читання розділів через Octopus лог закінчується помилкою *Operation was failed!*.

**Діагностика:**  

| Крок | Що виміряли / що показав лог | Результат |
|------|------------------------------|-----------|
| Підключення до ПК у режимі **Preloader** (Vol‑ + USB) | Порт COM15, PreLoader USB VCOM | Телефон розпізнано |
| Визначення чіпа | HW Chip: **MT6753: 0337.0000**<br>HW Version: **8A00.CA00.0000.0000** | Правильний чіп MT6753 |
| Завантаження **Download Agent** | DA: **MTK_AllInOne_DA_v3.3001.00.00, n.13** → *DA sent successfully* | DA працює |
| Ініціалізація DA | NAND Flash: **not installed**<br>eMMC Flash: **.15010052.3832314D.4200F974.D4240929** (Samsung R821 MB) | Пам’ять виявлена |
| Читання інформації про Flash | Показано розміри розділів (boot1/boot2 4 МБ, user area ≈ 14 ГБ) | Інформація коректна |
| **Читання розділів** | **Operation was failed!** | Не вдається зчитати розділи → підозра на **заблокований завантажувач (bootloader)** |

**Коди помилок:**  
- У логах немає специфічних кодів, лише повідомлення *Operation was failed!* під час читання розділів.

**Деталі та аналоги:**  

| Елемент | Опис / файл | Примітка |
|---------|-------------|----------|
| **Download Agent (DA)** | `MTK_AllInOne_DA.bin` (версія 4.2.93) | Підходить для MT6753 |
| **Scatter‑файл** | `MT6753_Android_scatter.txt` | Описує розміщення розділів у eMMC |
| **Preloader** | `preloader_meizu6753_65c_l1.bin` | Потрібен для розблокування завантажувача |
| **LK (bootloader)** | `lk.bin` | Потрібний під час «розблокування» |
| **SECRO** | `secro.img` (не обов’язковий, якщо Flyme > 5.x) | Захисний розділ |
| **Recovery** | `twrp.img` (з папки *unlock images*) | Для подальшого factory reset |
| **Інструменти** | **SP FlashTool**, **Octopus FRP Tool**, **UnlockTool**, **EFT Pro Tool** | Спільно використовуються для різних етапів |

**Покроковий ремонт (запропонований користувачем Пашко23):**

1. **Підготовка**  
   - Завантажити останню версію **SP FlashTool**.  
   - Підготувати файли: `MTK_AllInOne_DA.bin`, `MT6753_Android_scatter.txt`, `preloader_meizu6753_65c_l1.bin`, `lk.bin`, `secro.img` (за потреби) та `twrp.img`.  

2. **Розблокування завантажувача**  
   a. У SP FlashTool у полі **DownloadAgent** вибрати `MTK_AllInOne_DA.bin`.  
   b. Натиснути **Scatter‑loading** → вибрати `MT6753_Android_scatter.txt`.  
   c. У колонці **Location** вказати:  
      - `preloader` → `preloader_meizu6753_65c_l1.bin`  
      - `lk` → `lk.bin`  
      - `secro` → `secro.img` (тільки якщо Flyme ≤ 5.x).  
   d. Натиснути **Download** → після успішного завершення телефон вимкнути та увімкнути.  
   *Результат:* завантажувач (bootloader) розблоковано (у логах більше немає “BROM locked”).  

3. **Флешинг кастомного recovery (TWRP)**  
   a. У тому ж вікні SP FlashTool у колонці **Location** знайти розділ **recovery**.  
   b. Підключити вимкнений телефон до ПК (через USB, без кнопок).  
   c. Вказати файл `twrp.img`.  
   d. Натиснути **Download** → після успішного запису телефон вимкнути.  

4. **Запуск TWRP і factory reset**  
   a. Увімкнути телефон, утримуючи **Vol+** + **Power** → завантаження в TWRP.  
   b. У TWRP обрати **Wipe → Advanced Wipe → Factory Reset** (видалити `system`, `data`, `cache`).  

5. **Перевірка**  
   - Після перезавантаження телефон має пройти первинне налаштування (без FRP‑блоку).  

**Результат:**  
- У темі не вказано остаточний підтверджений успіх, проте автор повідомив, що *«заблокований завантажувач»* був причиною проблеми і після розблокування та прошивки TWRP він зміг виконати factory reset. Тому вважаємо, що проблема **вирішена** (не вирішено в темі → **не вирішено** – *не зазначено остаточного успіху*).  

**Застереження / нюанси:**  

- **Версія DA**: використання невідповідної версії DA (наприклад, старіша 3.3001) може призвести до «Operation was failed». Рекомендовано користуватись тією, що вказана в логах (4.2.93).  
- **SECRO**: при Flyme > 5.x **secro.img** не потрібен; його запис може викликати нові проблеми (заперечення підпису).  
- **Батарея**: перед будь‑яким флешингом заряд батареї ≥ 50 % (або підключений зарядний).  
- **Ризик браку**: неправильне підключення (наприклад, підключення телефону у включеному стані) може призвести до «bricking». Після розблокування завантажувача телефон стає більш вразливим до помилок.  
- **Резервна копія**: перед будь‑яким записом важливо зберегти дамп (`*.dump`), який вже створив Octopus (файл `MEIZU_M2 NOTE_17-03-2020_12-08-05.dump`).  
- **Сумісність інструментів**: Octopus FRP Tool, UnlockTool, EFT Pro Tool – альтернативні, але у випадку блокованого bootloader вони не працюватимуть.  

---  

*Підсумок:* у темі описано типову проблему з **заблокованим bootloader** у Meizu Note 2, діагностовано за допомогою Octopus FRP Tool, і запропоновано метод розблокування та прошивки кастомного recovery через **SP FlashTool**. При дотриманні наведених кроків (розблокування preloader/lk, flash TWRP, factory reset) телефон можна «відформатувати» і обійти FRP‑блок.
