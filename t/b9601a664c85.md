**Пристрій / модель:** Jeckery Explorer 2000 PRO (головна плата MCU).

**Симптом / несправність:** 
- Абсолютно мертва станція, відсутність дисплея та запуску ("ні дисплей, нічого").
- Інвертор попередньо згорів.
- При натисканні на перемикач SW1 чутний звук роботи BMS, але дисплей не вмикається.
- Кулер DC-DC вмикається 2–3 секунди і згасає при живленні головної плати з BMS + DC.
- При живленні від сонячних панелей (DC In) без головної плати — реакції немає.

**Діагностика:** 
- Початковий діагноз СЦ: непрацює центральна плата (MCU), потрібен запуск вручну.
- Другий СЦ (AMP): діагноз — потрібна донорська центральна плата.
- Подальша перевірка експертом: виявлено коротке замикання по живленню та пробій DATA-лінії SWD на мікроконтролерах.
- Вимірювання опору лінії 3.3V = 20 Ом (на одному з двох МК після віджигання).
- ⚠️ Згадана необхідність не менше 40В для запуску при напрузі акумулятора 35В (за чуток, потребує перевірки).

**Коди помилок:** 
- У темі не зазначено.

**Деталі та аналоги:** 
- **Мікроконтролери:** GD32 (три одиниці на платі), згадуються AVR, STM32 (як більш підходящі для роботи).
- **Інші компоненти:** Два транзистори біля конектора BMS (один зі слідами втручання, інший криво припаяний), кулер DC-DC, запобіжники, мікросхема захисту по напрузі.
- **BMS:** Існує 3 чи 4 версії BMS для цієї моделі; у темі BMS не ремонтувалась (попередники пожаліли).

**Покроковий ремонт:** 
1. Перевірка станції в СЦ: діагностували поломку MCU, запропонували донорську плату.
2. Вимірювання напруги на акумуляторі (35В).
3. Спроба живлення від DC In без головної плати — реакції немає.
4. Підключення головної плати з BMS + DC: кулер працює 2–3 сек, потім згасає.
5. Виявлення дефектів на головній платі (GD32): КЗ по живленню, пробій DATA-лінії SWD.
6. Віджигання кози (короткого замикання) на трьох пробитих МК для відновлення роботи програматором.
7. Прочитання вмісту програматором (два одразу, третій після повторного віджигання).
8. Заміна всіх трьох МК на нові.
9. Прошивка всіх МК.
10. Усунення кількох дефектів на всіх платах (крім BMS).

**Результат:** 
- Питання вирішено, станція відновлена професійним сервісом (компанія "Компас").
- Головні плати та МК відновлені/замінені.
- ⚠️ BMS не ремонтувалась у рамках цього процесу.

**Застереження / нюанси:** 
- Не вірити діагнозам СЦ без власної перевірки (можливі помилки в роботі сервісу).
- ⚠️ Напруга 35В на акумуляторі може бути недостатньою для запуску (згадана необхідність ≥40В, але це лише чуток).
- BMS є проблемним вузлом: існує кілька версій, вихід часто не запрацює навіть після заміни компонентів (проци, BQ, захист).
- При розборі інвертора слід уважно перевіряти підключення, щоб не згоріли інші компоненти ("щось забули відключити").
- Не рекомендується "добивати" станцію без кваліфікованого сервісу.
