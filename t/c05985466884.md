**Пристрій / модель:** Motorola G55 5G (XT‑2435‑2)  

**Симптом / несправність:**  
- Заблокований FRP (Factory Reset Protection).  
- При спробі ввімкнути телефон – лише “MTK device”, без входу у Fastboot.  
- Потрібен дамп пам’яті для подальшого прошивання.  

**Діагностика:**  
1. **Спроба зняти FRP** за допомогою програми **TSM** – результат: телефон не вмикається («невключайка»).  
2. **Дамп eMMC** – використано **ICP‑програматор f64** (у автора його не було, тому застосовано **UFI‑box**). Через UFI‑box записали «фул»‑образ у eMMC, потім зняли його назад, отримавши розділи.  
3. **Флеш** отриманих розділів через **Himera** – після заливки з’явилась заставка, проте в Fastboot не входить.  
4. **NV‑RAM** не прошито (автор зазначив, що цього не робив).  

**Коди помилок:** – відсутні у темі.  

**Деталі та аналоги:**  

| Елемент | Призначення / коментар |
|--------|------------------------|
| **TSM** | Програма для зняття FRP (не спрацювала). |
| **Pandora** | Утиліта для підняття (флешування) телефонів – не підтримує дану модель. |
| **ICP‑програматор f64** | Професійний програматор для повного дампу/запису eMMC (не був у автора). |
| **UFI‑box** | Альтернативний програматор, яким успішно записали і зняли дамп. |
| **Himera** | Флеш‑утиліта, якою залито отримані розділи. |
| **Fastboot** | Режим, у який телефон не входить після первинного флешу. |
| **NV‑RAM** | Пам’ять, що містить IMEI та інші параметри; не була прошита у процесі. |

**Покроковий ремонт:**  

1. **Спроба зняти FRP** через TSM → не вдалося (телефон не вмикається).  
2. **Отримання повного дампу**:  
   - Під’єднати телефон до програматора.  
   - Через **UFI‑box** записати «фул»‑образ у eMMC.  
   - За допомогою того ж пристрою зняти дамп назад, отримавши окремі розділи.  
3. **Флешування розділів**:  
   - Завантажити розділи у **Himera**.  
   - Залити їх у телефон. Після цього з’явилась стартова заставка.  
4. **Перевірка Fastboot** – режим не активується.  
5. **NV‑RAM** – не прошито (автор зазначив, що цього не робив).  
6. **Фінальна перевірка** – телефон завантажується, працює, IMEI на місці.  

**Результат:**  
Телефон успішно прошився, працює, IMEI збережено. **(Вирішено в темі)**  

**Застереження / нюанси:**  

- **Програматор f64** – оптимальний для повного дампу, без нього (як у автора) доводиться використовувати альтернативи (UFI‑box), що може ускладнити процес.  
- **NV‑RAM** часто містить IMEI та інші критичні дані; його не прошивати може призвести до відсутності IMEI або проблем з мережевою ідентифікацією. У даному випадку телефон працював без перепрошивки NV‑RAM, проте це не гарантується для інших випадків.  
- **Pandora** не підтримує Motorola G55 5G, тому її використання марне.  
- Після флешу **Fastboot** може залишатися недоступним – це типово для деяких MTK‑платформ, коли завантажувальний лоадер (preloader) не активований. Якщо потрібен Fastboot, треба перепрошити відповідний bootloader/ preloader.  
- При роботі з програматорами та флеш‑утилітами **завжди робіть резервну копію** оригінального дампу, щоб мати можливість відновити стан у випадку помилки.  
- Використання **правильних образів розділів** (з урахуванням регіону, версії прошивки) критично; неправильний файл може привести до «brick».
