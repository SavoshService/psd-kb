**Пристрій / модель:** POCO X3 Pro  

**Симптом / несправність:**  
- Питання користувача: як оновити телефон до MI UI 14.  
- Після спроби прошивки через Fastboot виникає небажаний результат (можливе «закирпичування» пристрою).  

**Діагностика:**  
*У темі не зазначено жодних вимірювань, логів чи скріншотів.*  

**Коди помилок:**  
*Не вказані.*  

**Деталі та аналоги:**  
- Для прошивки через Fastboot необхідно **розлочити (розблокувати) завантажувач** (bootloader).  
- У відповіді користувача *yurik96* зазначено, що «Розлочка загрузчика тільки так».  
- Немає інформації про конкретні файли прошивки, їх контрольні суми, чи використані інструменти (Mi Flash, Fastboot тощо).  

**Покроковий ремонт:**  
| Крок | Опис дії (за даними теми) |
|------|---------------------------|
| 1 | Розблокувати завантажувач (bootloader) – єдиний спосіб, згідно з коментарем *yurik96*. |
| 2 | Запустити прошивку MI UI 14 через Fastboot (не уточнено, які саме файли чи команди). |
| 3 | Після успішної прошивки користувач повідомив, що «стало в якихось питаннях краще», проте деталі не наведені. |

**Результат:**  
- У темі немає чіткого підтвердження успішного оновлення або опису остаточного стану пристрою. → **не вирішено в темі**.  

**Застереження / нюанси:**  
- **⚠️ потребує перевірки** – твердження про «можливе закирпичування» при неправильній прошивці є типовим, проте конкретних випадків або помилок не наведено.  
- Розблокування завантажувача стирає всі дані на телефоні та скасовує гарантію.  
- Після розблокування необхідно переконатися, що використовується офіційна (або перевірена) прошивка MI UI 14, сумісна саме з POCO X3 Pro.  
- Рекомендовано створити повний бекап (наприклад, за допомогою TWRP) перед будь‑якими діями через Fastboot.  
- Після прошивки можуть залишитися залишкові дані старої прошивки (наприклад, залишкові кеші, невидалені системні розділи), тому після оновлення бажано виконати **wipe data/factory reset**.  

---  

*Примітка:* У темі відсутня технічна інформація про конкретні команди Fastboot, контрольні суми файлів прошивки, чи результати тестування (наприклад, перевірка підключення в режимі Fastboot, статус розблокування). Тому розбір обмежений лише вказаними у постах фактами.
