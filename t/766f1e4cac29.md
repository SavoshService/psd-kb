## 7. ZTE (Spreadtrum) – діагностика з **Hydra Tool**  

**Пристрій / модель:** ZTE‑пристрій (ідентифікований у Hydra Tool, ймовірно **ZTE V30 / Tiger618**).  

**Симптом / несправність:**  
- Після спроби резервного копіювання пам’яті процес зупинився на розділі **super**.  
- Телефон не вмикається, раніше був **bootloop**, потім стабільний **recovery**.  
- При натисканні кнопки споживання ≈ 70 mA → ознака відсутності ініціалізації пам’яті (EMMC не стартує).  

**Діагностика:**  
| Параметр | Значення |
|----------|----------|
| **Hydra Tool** – версія | 2024.3.18.2 |
| **OS** | Windows 11 22H2 (64‑bit) |
| **Dongle** | версія 1.3, серійний 190900002122, статус **Activated**, Life 0 |
| **Port** | COM13 (відкрито) |
| **HW‑версія** | `sc7731e_modem` |
| **Build‑номер** | `731F50V1.0.0B20` (28‑09‑2020) |
| **IMEI** | 863808054420569, 863808054450566, 867400020316638, 867400020316646 |
| **Simlock** | OFF |
| **Error** | `BSL_REP_UNSUPPROT_COMMAND` |
| **Автобекап Security Partition** | Файли `prodnv.bin`, `uboot_a.bin`, `uboot_b.bin`, `uboot_log.bin`, `l_fixnv1_a.bin`, … – всі **OK** |
| **Час виконання** | 00:01:44 |

**Коди помилок:** `BSL_REP_UNSUPPROT_COMMAND` – команда, яку BSL (Bootloader) не підтримує (часто через несумісність прошивки/версії інструмента).  

**Деталі та аналоги:**  
- Чип **SC7731E** (Spreadtrum/Unisoc).  
- Для роботи з цим чипом часто використовують **UnlockTool**, **Hydra Tool**, **SP Flash Tool**.  

**Покроковий ремонт (теоретичний, не виконаний у темі):**  
1. **Перевірка живлення** – підключити стабільне 5 V/2 A джерело, виміряти струм (повинен бути > 200 mA при ініціалізації).  
2. **Перепрошивка Bootloader** – використати **Hydra Tool** з правильним **loader** (Loader 1/2) та **scatter‑файлом** для SC7731E.  
3. **Flash “super” розділу** – якщо авто‑бекап успішний, спробувати flash `super.img` (або `system.img` + `vendor.img`) через **SP Flash Tool** у режимі **Download Only**.  
4. **Перевірка BSL** – у випадку `UNSUPPROT_COMMAND` спробувати оновити **Hydra Tool** до новішої версії або використати **Qualcomm HS‑USB** драйвери.  
5. **Тестування** – після flash‑у запустити **fastboot**/ **adb** для перевірки доступності `fastboot devices`.  

**Результат:** не вирішено в темі (жодних успішних дій не зазначено).  

**Застереження / нюанси:**  
- **70 mA** споживання вказує на **EMMC** без живлення або з пошкодженим **VCCQ**/`VCC`. Перевірити напругу на контактах eMMC (1.8 V, 3.3 V).  
- При використанні **Hydra Tool** важливо, щоб **dongle** був **Activated** і **Life** не був 0 (може означати закінчений лічильник використання).  
- Команда `BSL_REP_UNSUPPROT_COMMAND` часто зникає після **перепрошивки BSL** (завантаження нової версії `loader`).
