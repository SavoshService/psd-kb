## Розбір теми «Резервна копія прошивки зарядної станції BLUETTI EB55»

| Пункт | Інформація |
|-------|------------|
| **Пристрій / модель** | **Bluetti EB55** – портативна зарядна станція. У центрі уваги мікроконтролер **STM32F030R8T6**. |
| **Симптом / несправність** | У темі не вказано конкретного симптому. Публікація присвячена лише створенню **резервної копії прошивки** (можливе використання при відновленні ПЗ після збою). |
| **Діагностика** | Описано процес зчитування флеш‑пам’яті мікроконтролера за допомогою **ST‑LINK** (SWD). <br>**Лог зчитування:** <br>```\n14:42:33:214 : ST‑LINK SN  : 3B1E0201*********\n14:42:33:214 : Voltage     : 3.18V\n14:42:33:214 : SWD freq    : 4000 KHz\n14:42:33:216 : Device ID   : 0x440\n14:42:33:216 : Revision ID : Rev 2.0\n…\nUPLOADING ... Size : 65536 Bytes, Address : 0x8000000\nData read successfully\n```<br>Зчитано: <br>• **Option bytes** – 16 Б (адреса 0x1FFFF800) <br>• **Flash** – 4 × 64 KB блоки (загалом 256 KB) з адреси 0x8000000. <br>Час зчитування – < 0.5 с на блок. |
| **Коди помилок** | Не зазначено. |
| **Деталі та аналоги** | - **Мікроконтролер:** STM32F030R8T6 <br>  - ARM Cortex‑M0, 64 KB Flash, 8 KB RAM <br>  - 2 × UART, 2 × I2C, 2 × SPI, ADC <br>  - Корпус **LQFP‑64** <br>- Аналоги в інших моделях Bluetti можуть бути інші контролери сімейства STM32F0, проте в EB55 саме цей. |
| **Покроковий ремонт** | У темі **не описано** жодних ремонтних дій. Надано лише: <br>1. Дамп прошивки (лог зчитування). <br>2. Файл прошивки **EB55_0 V3.0.bin** (додаток). <br>Тобто, можливий **процес перепрошивки**: <br>1. Підключити ST‑LINK до SWD‑контактів контролера. <br>2. Переконатися, що живлення контролера ≈3.3 V (у логі – 3.18 V). <br>3. За допомогою STM32CubeProgrammer або аналогічного ПЗ записати файл *.bin* у флеш‑пам’ять за адресою 0x8000000. |
| **Результат** | **Не вирішено в темі.** Публікація містить лише дані для резервного копіювання та файл прошивки, без підтвердження успішного відновлення чи тестування. |
| **Застереження / нюанси** | - **Перепрошування без точного знання версії** прошивки може «запалити» (brick) пристрій. <br>- Потрібно **перевірити контрольні суми** (CRC, MD5) файлу `EB55_0 V3.0.bin` перед записом. <br>- Під час запису слід дотримуватись **SWD‑частоти ≤4 MHz** (як у логі) та стабільного живлення контролера (≥3 V). <br>- Резервна копія корисна лише у випадку **апаратних пошкоджень ПЗ** (наприклад, після некоректного оновлення). Не вирішує проблеми з **електронними компонентами** (MOSFET, конденсатори, трансформатори). <br>- Запит про перешивання 110 V станції на 220 V (пости 3‑4) **не стосується прошивки** і вимагає заміни трансформаторів, що виходить за межі даної теми. **⚠️ потребує перевірки** (можливість, безпека, сертифікація). |
| **Висновок** | Тема слугує як **джерело резервної копії прошивки** для Bluetti EB55. Ніяких симптомів, діагностичних вимірювань (окрім напруги живлення) чи кроків ремонту не наведено. Для практичного використання необхідно мати досвід роботи з STM32, ST‑LINK та програмним забезпеченням для перепрошивки. |
