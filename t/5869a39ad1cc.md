**Пристрій / модель:** Motorola E15 (XT2523‑6)  

**Симптом / несправність:**  
- Блокування FRP (Factory Reset Protection) після скидання налаштувань або після втрати доступу до облікового запису Google. Користувач потребує скидання FRP, щоб знову ввійти в пристрій.

**Діагностика:**  
- Використано програму **Android Multi‑Tool** (FRP Reset) через USB‑кабель.  
- Після підключення виведено наступний лог:

```
Searching for usb device... Found
MediaTek PreLoader USB VCOM_V1632 (Android) (COM28)
Connecting to device...Ok
ChipId : MT6768 [Helio P65/G85 K68V1], SW Ver : 0000, HW Ver : CA00
Sending Download‑Agent to device... Ok
Authorizing device for operations... Ok
Reading partition information... Ok [128]
Reading system information...
Chipset Type : armeabi‑v7a
Security Patch : 2025‑10‑01
Build Date : Fri Sep 26 11:18:45 CST 2025
Build Number : UUTB34.40‑41
Incremental : 40‑41
Device Model : moto e15
SDK Version : 34
Device Brand : motorola
Android Ver : 14
Reading partition information... Ok [128]
Formatting desired partition... Ok
Rebooting device... Ok
.
Все Успішно.
```

- **Отримані значення:**  
  - Чіп: **MT6768 (Helio P65/G85 K68V1)**  
  - Android 14, SDK 34, Security Patch 2025‑10‑01  
  - Пакет прошивки: **UUTB34.40‑41** (build 40‑41)  
  - Підтверджено успішне форматування потрібного розділу та перезавантаження.

**Коди помилок:** відсутні (успішне виконання всіх кроків).

**Деталі та аналоги:**  
- **ChipId MT6768** – типова платформа MediaTek Helio P65/G85, використовується в багатьох бюджетних смартфонах.  
- **Android Multi‑Tool** – універсальна утиліта для роботи з MediaTek‑пристроями (FRP Reset, Unlock, Flash, etc.).  
- Аналогічні інструменти: **SP Flash Tool**, **MTK Droid Tools**, **Maui Meta** (для розблокування завантажувача).  
- Для даної моделі FRP можна скинути, форматуючи розділ **userdata** (або інший, зазначений інструментом) без необхідності розблоковувати bootloader.

**Покроковий ремонт:**  

| Крок | Опис дії | Примітка |
|------|----------|----------|
| 1 | Підключити телефон до ПК через USB‑кабель, увімкнути режим **Download / Preloader** (зазвичай автоматично при підключенні, якщо телефон вимкнено). | У логі видно `MediaTek PreLoader USB VCOM_V1632`. |
| 2 | Запустити **Android Multi‑Tool**, обрати функцію **FRP Reset**. | |
| 3 | Програма виявляє пристрій (`Found`), встановлює з’єднання (`Connecting… Ok`). | |
| 4 | Передається **Download‑Agent** (DA) – підтверджено (`Sending Download‑Agent… Ok`). | |
| 5 | Авторизація пристрою (`Authorizing device… Ok`). | |
| 6 | Читаються розділи та системна інформація (Chipset, Security Patch, Build Number, SDK, Android version). | Дозволяє переконатися, що прошивка відповідає очікуваній. |
| 7 | Форматується потрібний розділ (зазвичай **userdata**), що містить дані FRP. (`Formatting desired partition… Ok`). | |
| 8 | Пристрій перезавантажується (`Rebooting device… Ok`). | |
| 9 | Після перезавантаження FRP більше не активовано – телефон проходить первинне налаштування без запиту Google‑акаунту. | Підтверджено рядком «Все Успішно». |

**Результат:**  
- FRP успішно скинуто, телефон готовий до первинного налаштування.  
- У темі зазначено «Все Успішно», отже проблема вирішена.

**Застереження / нюанси:**  

- **Легальність** – скидання FRP без дозволу власника пристрою може порушувати законодавство про захист інформації. Виконуйте лише на власних пристроях або за письмовою згодою власника.  
- **Ризик «брікінгу»** – неправильний вибір розділу або використання невідповідної прошивки може призвести до незавантажуваного пристрою. Перевіряйте, що обрана прошивка (UUTB34.40‑41) відповідає вашій версії (XT2523‑6).  
- **Потужність USB‑порту** – під час передачі DA та форматування розділів важливо, щоб порт забезпечував стабільний струм (≥500 мА). Падіння живлення може призвести до зависання процесу.  
- **Бекап** – FRP Reset стирає всі дані користувача. Якщо потрібен бекап, його треба робити до скидання (наприклад, через режим **fastboot** або **adb**, якщо пристрій ще розблокований).  
- **Використання інших інструментів** – у відповіді користувача Dminтро запитував про «Unlock Tool». Якщо потрібне розблокування завантажувача (bootloader), це вже інша процедура, що вимагає OEM‑ключів і може скинути FRP знову.
