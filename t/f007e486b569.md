**Пристрій / модель:** BLUETTI Elite 100 V2 (плати синуса)

**Симптом / несправність:** Процесор AT32F403ARCT7 вийшов з ладу (коротке замикання по 3.3В). Потрібна заміна та прошивка нового чипа.

**Діагностика:** 
- Вимірювання напруги на старому процесорі показало коротке замикання по 3.3В.
- Перевірка EPROM 24C08 (неясно, чи містить прошивку чи це оперативна пам'ять).
- Спроби розпізнати чип через звичайні програматори не вдалася.

**Коди помилок:** Не зазначено

**Деталі та аналоги:** 
- Процесор: AT32F403ARCT7 (LQFP64).
- Прошивки: `Bluetti_Elite100_V2_Invertor_AT32F403ARCT7_PLP_M1_V3.0_2024_12_20.rar`, `Bluetti_Elite100_V2_BMS_AT32F423RCT7.rar` (⚠️ у назві файлу BMS вказано інший тип чипа AT32F423RCT7).

**Покроковий ремонт:** 
1. Заміна процесора на новий (донорський/з Китаю).
2. Підготовка програматора CH341A Pro (джампер у положенні UART / TTL).
3. Налаштування підключення: Пін 42 (PA9) → RX, Пін 43 (PA10) → TX, Пін 63 (VSS) → GND, Пін 64 (VDD) → 3.3В.
4. Активація бутлоадера: Пін 60 (BOOT0) підтягнути до 3.3В перед увімкненням USB.
5. Перезапуск при відсутності відповіді: Короткочасне замикання Пін 7 (NRST) на GND.
6. Програмування через Artery ISP Programmer (Режим UART, Швидкість 115200 або 57600, Адреса старту 0x08000000).

**Результат:** Процесор розпізнався і успішно прошився. БМС також отримав окрему прошивку.

**Застереження / нюанси:** 
⚠️ Функція EPROM 24C08 неясна (питання, чи це пам'ять чи прошивка).
⚠️ Розпіновка чипа специфічна для цього варіанту підключення.
