## Пристрій / модель
**Nokia G11**, ревізія **TA‑1401** (за наклейкою/коробкою).  

## Симптом / несправність
1. **“no valid os found”** – телефон перезавантажується.  
2. Зависання на білому екрані з логотипом Android One, немає входу в Recovery, лише Fastboot.  
3. При підключенні до зарядки телефон одразу переходить у білий екран; після відключення – лише індикатор живлення.  
4. У Fastboot‑режимі команди не виконуються (відмова в авторизації).  

## Діагностика
| Дія | Результат |
|-----|-----------|
| `fastboot devices` – перевірка підключення | Пристрій видно в Fastboot. |
| `fastboot erase userdata` | **FAILED (remote: 'permission denied, auth needed.')** – відмова в авторизації. |
| `fastboot -w` або `fastboot erase userdata` | Та ж помилка. |
| `fastboot reboot` | Перезавантаження без зміни стану. |
| Перехід у режим **FDL** (утримання **Vol‑ + Vol+**, підключення Type‑C) | Поява синіх індикаторів **FDL1/FDL2**, далі **System**, зелений статус **Passed** (при успішному вході в режим). |
| Спроба прошивки через **SPD Upgrade Tool** з .pac‑файлом TA‑1401 | При появі **FDL Auth Failed** – потрібен обхід захисту (Pandora Box/UnlockTool). |
| Повне відключення живлення (зняти кришку, від’єднати акумулятор, зачекати ~2 сек., під’єднати) | Не вплинуло на подальший результат. |

## Коди помилок
- **FD_Auth** – помилка авторизації в SPD Tool.  
- `FAILED (remote: 'permission denied, auth needed.')` – Fastboot відмовляє в виконанні команд без авторизації.  
- **FDL Auth Failed** – не вдалося пройти захист під час прошивки в режимі FDL.  

## Деталі та аналоги
| Елемент | Опис |
|---------|------|
| **Прошивка** | `.pac`‑файл **Nokia_G11_HMDSW_SCT_138F‑0‑00WW‑B01_User_DeviceKit** (підходить саме під ревізію TA‑1401). |
| **Програми/флешери** | `SPD Upgrade Tool` (або Research Download Tool) – для прошивки .pac у режимі FDL. <br> `Fastboot` – базові команди. |
| **Драйвери** | Spreadtrum/Unisoc USB Drivers (SCI USB2Serial). |
| **Обхід захисту** | `Pandora Box`, `UnlockTool`, `Infinity CM2 SP2` – потрібні для авторизації в режимі FDL/fastboot. |
| **Альтернативи** | Офіційний сервіс Nokia (вартість ≈ 600 грн) – прошивка без обхідних засобів. |
| **Інші інструменти** | `USB Redirector` (платний) – можливість віддаленої прошивки (не використано). |

## Покроковий ремонт (те, що пробували)
1. **Перевірка підключення** – `fastboot devices`.  
2. **Спроба очистки даних** – `fastboot -w` / `fastboot erase userdata` → **невдача** (auth needed).  
3. **Перезавантаження** – `fastboot reboot`.  
4. **Вхід у режим FDL** – утримання **Vol‑ + Vol+**, підключення Type‑C, очікування індикаторів FDL1/FDL2 → **Passed** (без авторизації).  
5. **Прошивка .pac** через **SPD Upgrade Tool** – при успішному вході в режим FDL, але під час запису з’являється **FDL Auth Failed**.  
6. **Спроба обійти захист** – згадка про використання Pandora Box/UnlockTool (не виконано).  
7. **Повне відключення живлення** – зняти кришку, від’єднати батарею, підключити назад (не допомогло).  

## Результат
- Після спроби прошивки **телефон не включився** (пост 26).  
- Подальші обговорення (пости 27‑32) вказують, що без спеціального програматора (Pandora Box/UnlockTool) успішна прошивка **не можлива**.  
- Рекомендовано звернутись у **офіційний сервіс Nokia** (вартість ≈ 600 грн).  
- Тобто, в темі **не вирішено** проблему.

## Застереження / нюанси
- **Авторизація** в Fastboot та FDL захищена; без Pandora Box/UnlockTool команди `fastboot erase` та прошивка .pac будуть блоковані.  
- **Ризик “дестройту”** (пошкодження завантажувача) після розблокування, про що згадував користувач *MrFreeze* (пост 14).  
- **Фізичний доступ** до пристрою обов’язковий – віддалене прошивання можливе лише через платні рішення (USB Redirector).  
- **Офіційна прошивка** (через сервіс) – найнадійніший шлях, якщо плата та інші компоненти справні.  
- При роботі з **SPD Upgrade Tool** важливо точно вибрати .pac‑файл, що відповідає ревізії TA‑1401; інший файл може призвести до “no valid os found”.
