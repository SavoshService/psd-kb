**Пристрій / модель**  
- GD GD32F310K8T6, корпус LQFP‑32 (ARM Cortex‑M3, 72 МГц, 64 КБ Flash, 20 КБ RAM).  

**Симптом / несправність**  
- Проблема з прошивкою: програматор **ST‑Link** лише читає мікроконтролер, запису не виконує.  

**Діагностика**  
- Перевірка можливості запису здійснена за допомогою ST‑Link (відсутній запис).  
- Програмування успішне лише через **J‑Link** (вказано, що саме цим програматором можна прошивати).  

**Коди помилок**  
- В темі не зазначено жодних кодів помилок.  

**Деталі та аналоги**  
| Параметр | Значення |
|----------|----------|
| Ядро | ARM Cortex‑M3 |
| Частота | до 72 МГц |
| Flash | 64 КБ |
| RAM | 20 КБ |
| Корпус | LQFP‑32 |
| Сумісність | Працює з інструментами, сумісними зі STM32F1 (але не з усіма ST‑Link). |
| Аналоги | STM32F103C8T6 (за функціоналом), інші GD32F3‑серії. |

**Покроковий ремонт**  
1. **Вибір програматора** – використати J‑Link (або інший програматор, що підтримує GD32).  
2. Підключити мікроконтролер до програматора (SWD‑інтерфейс).  
3. Перевірити зв’язок (чтення ID).  
4. Завантажити прошивку у Flash через J‑Link.  
5. Перевірити успішність запису (чтення back‑verify).  

*Примітка:* У темі автор не проводив самих кроків, лише зазначив, що J‑Link працює, а ST‑Link – ні.  

**Результат**  
- У темі питання не було вирішено: мікроконтролери продані, подальша підтримка не надавалась.  

**Застереження / нюанси**  
- **⚠️** Програмування GD32F310K8T6 **ST‑Link**‑ом може бути неможливим або потребувати спеціального firmware/конфігурації; без цього запису не відбудеться.  
- При спробі прошивки без належного програматора існує ризик «запороти» мікроконтролер (втрата можливості запису).  
- Якщо немає досвіду у програмуванні мікроконтролерів, доцільніше купити готову BMS‑плату, а не окремий контролер.
