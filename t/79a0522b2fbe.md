**Пристрій / модель:** EcoFlow DELTA (MR300), плата BMS MR300-BMS-V1.0.3

**Симптом / несправність:** Необхідність визначення номіналу резисторів на платі BMS для ремонту або заміни компонентів.

**Діагностика:** 
- Перевірка резистора R140 (запит на номінал).
- Перевірка резистора R93 біля RXTX.
- Згадка про наявність «нульовика» (компонент 0 Ом) та можливі короткі замикання в перетворювачах БМС.

**Коди помилок:** Немає інформації.

**Деталі та аналоги:** 
- Резистори: R140, R93.
- Плата: MR300-BMS-V1.0.3.

**Покроковий ремонт:** 
1. Користувач запитав номінал резистора R140 на платі BMS (фото прикріплено).
2. Інший користувач порадив шукати короткі замикання по перетворювачах БМСки.
3. Запит щодо резистора R93 біля RXTX.
4. Вимірювання/перевірка на місці підтвердило значення для R93.

**Результат:** Номінал резистора R93 визначено як 220 Ом. Значення резистора R140 у тексті не підтверджено (лише запит). Тема не завершена повністю щодо всіх компонентів.

**Застереження / нюанси:** 
- ⚠️ потребує перевірки — при пошуку проблем радять звернути увагу на замикання по перетворювачах БМСки.
