## Розбір теми «bq Evaluation Software (bqEVSW) програма»

| Пункт | Інформація |
|-------|------------|
| **Пристрій / модель** | • **Контролер акумулятора:** BQ30Z55 (TI)  <br>• **Програматор:** EV2400 (працює з BQ30Z55)  <br>• **Програмне забезпечення:** BQ Evaluation Software (bqEVSW) – різні збірки, зокрема `bqEVSWSetup00.09.74_bq30z55v0.21a.zip`, `bqEVSWSetup00.09.90_bq30z55v0.36R3c.zip`, `bqEVSWSetup00.09.92_bq30z55v0.36R3c.zip`, `bqEVSWSetup00.09.92_bq30z55v0.36R3d.zip`, `bqEVSWSetup00.09.92_bq30z55v0.37R3f.zip`. |
| **Симптом / несправність** | Блокування контролера BQ30Z55: команда **UNSEAL** не виконується, стандартний (заводський) **unseal‑ключ** не підходить. |
| **Діагностика** | • Підключення батареї до програматора EV2400. <br>• Запуск bqEVSW. <br>• Спроба виконати `UNSEAL` з використанням заводського ключа (зазвичай `0x80008000` або `0x04140214` – залежно від прошивки). <br>• Результат: **UNSEAL не вдається** (повідомлення про помилку, відсутність зміни статусу). <br>• Ніяких вимірювань (напруги, температури, стану регістрів) у темі не зазначено. |
| **Коди помилок** | Не вказані. |
| **Деталі та аналоги** | • **EV2400** – підтверджено працює з BQ30Z55 (пост №3). <br>• **EV2300** – питання, чи працює, без відповіді (пост №2). <br>• Для іншого контролера **BQ20Z75** вказана робоча збірка `bqEVSWSetup00.09.59_bq20z75v1.81a.zip` (пост №7). <br>• У пості №1 наведено кілька версій bqEVSW для BQ30Z55, які можна завантажити після досягнення 15‑ти дописів або за оплату. |
| **Покроковий ремонт** | У темі **не наведено** жодного покрокового рішення. Є лише запит на зміну ключа на «рандомний» та виконання `UNSEAL`. |
| **Результат** | **Не вирішено в темі** – користувач залишився без відповіді щодо отримання/генерації нового unseal‑ключа. |
| **Застереження / нюанси** | • **Unseal‑ключ** – це 32‑бітовий захисний код, який задається виробником. Без нього `UNSEAL` неможливий. Генерація випадкового ключа без знання оригінального не відкриває контролер – потрібен **правильний** ключ або спеціальна процедура «key‑reset», яку підтримують лише певні прошивки/версії bqEVSW. <br>• Використання **неправильного** ключа або некоректних команд може призвести до **перманентного блокування** (permanent seal) контролера, після чого його вже не розблокувати. <br>• Для BQ30Z55 часто використовується **заводський ключ** `0x80008000` (для старих прошивок) або `0x04140214` (для нових). Якщо контролер був перепрограмований, ключ може бути іншим. <br>• **EV2400** підтверджено працює з BQ30Z55, а **EV2300** – не підтверджено (можливі обмеження у підтримці протоколу). <br>• При роботі з bqEVSW необхідно мати **правильну версію** програми, сумісну з конкретною ревізією мікросхеми (наприклад, `bqEVSWSetup00.09.92_bq30z55v0.37R3f.zip` для нових ревізій). |
| **⚠️ Потребує перевірки** | • Чи існує офіційна процедура «reset unseal key» у bqEVSW для BQ30Z55 (можливе використання **“Random Key”** функції). <br>• Яка саме **версія** bqEVSW потрібна для розблокування конкретної ревізії BQ30Z55 (залежить від `bq30z55vX.Y` у назві файлу). |

### Короткий висновок
Тема містить лише **запит** користувача щодо розблокування контролера BQ30Z55 за допомогою програматора EV2400 і програми bqEVSW. Ніяких діагностичних вимірювань, кодів помилок чи конкретних кроків ремонту не наведено. Питання про **unseal‑ключ** залишилося без відповіді, тому проблему в темі **не вирішено**. Для подальшого розв’язання необхідно:

1. Визначити точну ревізію BQ30Z55 (наприклад, `bq30z55v0.37R3f`).  
2. Підібрати відповідну збірку bqEVSW.  
3. Спробувати стандартні заводські ключі (`0x80008000`, `0x04140214`).  
4. Якщо вони не підходять – шукати в офіційній документації TI або у спеціалізованих спільнотах (наприклад, **Battery University**, **DIY Battery**), процедуру **key‑reset** або **random‑key generation**.  

Без цих кроків розблокувати контролер неможливо, а неправильні дії можуть призвести до **перманентного блокування**.
