## Розбір теми «Brevia, коди помилок, загальна інфа»

---

### Пристрій / модель
| Модель | Примітка |
|--------|----------|
| **Brevia ePower 1000 Portable Power Station 1000 W** (Article 41000) | 1000 W, синхронізатор, вихідний міст з клеєними транзисторами, радіатор без отворів. |
| **Brevia 1000 W LiFePO₄** (Article 31000) | 3S2P LiFePO₄, BMS без балансира, клема «+» – алюміній, клема «‑» – мідь. |
| **Brevia 500 W NCA** (Article 30500 PS / 30300) | Пасивне охолодження, схожа «морда» (корпус) у всіх варіантах. |

> **Примітка:** У темі згадуються й інші моделі (наприклад, «Brevia 500 W NCA»), проте конкретних технічних даних лише для вищевказаних.

---

### Симптом / несправність
| Код | Опис (з теми) | Додаткові коментарі |
|-----|---------------|----------------------|
| **E01 – E36** | Перелік типових помилок (перевантаження входу, температури, BMS‑захисти тощо). | Дано схеми розташування резисторів/транзисторів, які відповідають за захист. |
| **E37** | «Відсутність комунікації головної плати з інвертором». У реальних умовах часто – **випалений інвертор** через коротке замикання. | Поява без очевидної закономірності на різних моделях. |
| **E67** | «Проблеми з вентилятором», проте підтвердження не гарантоване. | Може бути як реальна, так і помилкова діагностика. |
| **Перегрів у режимі UPS** | При довготривалому навантаженні станція «любить перегріватись». | Пассивне охолодження, відсутність вентилятора. |
| **Фізичний дефект** | Керамічна смужка з транзисторами приклеєна без отворів у радіатор; BMS без балансира; «дуті» комірки. | Ускладнює ремонт, потребує демонтажу/заміни. |

---

### Діагностика (з теми)

| Дія | Що вимірювали / перевіряли | Отримані значення / висновки |
|-----|---------------------------|------------------------------|
| **Перевірка коду помилки** | Читання коду через індикатор/дисплей. | Виявлені коди E01‑E36, а також E37, E67. |
| **Візуальний огляд інвертора** | Перевірка стану керамічної смужки, наявність перегорілих транзисторів. | При E37 часто виявляється «випалений інвертор». |
| **Тест радіатора** | Огляд наявності отворів, стан керамічної смужки. | Радіатор без отворів, смужка приклеєна, ускладнює охолодження. |
| **Перевірка BMS** | Огляд резисторів (R176, R180, R186/188) та AFE‑модулів. | Вказано, які елементи відповідають за конкретні коди (E08‑E16, E20‑E36). |
| **Тест вентиляторa** (для E67) | Перевірка обертання, напруги на вентиляторі. | Немає даних про конкретні вимірювання – лише припущення. |

> **Примітка:** У темі немає конкретних вимірювань напруг/струмів, лише описові діагностичні кроки.

### Деталі та аналоги (компоненти, схеми, технології)

| Елемент | Призначення | Примітки з теми |
|---------|-------------|-----------------|
| **R125 / U25** | Захист від надмірного негативного струму на вході DC/PV | E01 |
| **U22B** | Захист від над/недо‑напруги на вході DC/PV | E02, E03 |
| **R186 / R188** | Датчики температури (низька/висока) під час зарядки/розряду | E08‑E11 |
| **R191 / U12B**, **R192 / U23** | Датчики струму на сигаретному розетковому порті, USB/PD | E18 |
| **R176** | Температурний датчик BMS (захист від перегріву, криогенний режим) | E20‑E22, E30‑E31 |
| **R180** | MOS‑транзистор BMS (температурний захист) | E22 |
| **AFE (Analog Front End)** | АЦП/цифрові блоки, що вимірюють напругу/температуру/струм BMS | Більшість BMS‑кодових помилок |
| **C95, C87** | Датчики MOS‑транзисторів (розряд/заряд) | E34, E35 |
| **Керамічна смужка** | Пакет транзисторів (IGBT/ MOSFET) приклеєний без отворів до радіатора | У ePower 1000 – ускладнює ремонт |
| **Радіатор без отворів** | Охолоджуючий елемент без вентиляційних отворів | Потрібно свердлити отвори під гвинти/прокладки |
| **Точка зварки (потужна точкова сварка)** | Спосіб з’єднання металевих клем (алюміній, мідь) у батареї | Використовується для зварювання клем у LiFePO₄‑моделях |
| **Пасивне охолодження** | Відсутність вентилятора, залежність від радіатора | Приводить до перегріву у режимі UPS |

### Покроковий ремонт (з теми)

| Крок | Опис дії | Коментар |
|------|----------|----------|
| **1. Діагностика коду помилки** | Зчитати код через дисплей. Якщо E37 – підозра на інвертор. | Якщо інший код – перевірити відповідний елемент (резистори, AFE, MOS). |
| **2. Візуальний огляд інвертора** | Перевірити керамічну смужку, наявність перегорілих транзисторів, стан радіатора. | При E37 часто виявляються «випалені» ділянки. |
| **3. Демонтаж керамічної смужки** | *Зняти* керамічну смужку (можна нагрівом, скотч‑медіатором). | Після зняття – підготовка радіатора до свердління. |
| **4. Свердління отворів у радіатор** | Свердлити 8 отворів (по кількості транзисторів) для монтажу на гвинти. | Використовують **силіконові прокладки** (стандартні) між радіатором і корпусом. |
| **5. Прикріплення інвертора** | Прикріпити інвертор до радіатора за допомогою гвинтів + силіконових прокладок. | Простіший варіант – **клей** (не рекомендовано, нестійко). |
| **6. Відновлення BMS** | При потребі – замінити/перепаять резистори R176, R180, R186/188. | Для LiFePO₄‑моделей – **потужна точкова сварка** клем (алюміній/мідь). |
| **7. Перевірка вентиляції** (для E67) | Перевірити роботу вентилятора, підключити живлення, виміряти напругу. | Якщо вентилятор не крутиться – замінити. |
| **8. Тестування** | Після ремонту – включити станцію, перевірити відсутність коду помилки, виміряти вихідну потужність, температуру інвертора. | Якщо код зникає – ремонт успішний. |

> **Примітка:** У темі не наведено конкретних схем підключення чи параметрів напруг/струмів, тому кроки орієнтовані на загальноприйняті практики для цих моделей.

### Результат

| Симптом | Висновок у темі |
|---------|-----------------|
| **Код E37** | Не вирішено в темі – лише припущення, що це «випалений інвертор». |
| **Код E67** | Немає підтвердження, що проблема вирішена; лише зазначено можливу причину (вентилятор). |
| **Перегрів у режимі UPS** | Не надано рішення; зазначено, що станція має пасивне охолодження і схильна до перегріву. |
| **Ремонт інвертора (керамічна смужка, радіатор)** | Описано метод «зняти смужку → свердлити отвори → встановити з силіконовими прокладками». Немає даних про успішність у конкретному випадку. |
| **Зварка клем у LiFePO₄** | Рекомендовано **потужну точкову сварку**; результат не підтверджений у темі. |
