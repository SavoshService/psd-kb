**Пристрій / модель:** Oukitel P1000ePlus

**Симптом / несправність:** 
Після заміни плати інвертора відсутній старт при стандартному підключенні (через R-). Прилад видає піки, кнопка живлення "дихає". БМС вмикається та світиться. При прямому підключенні B+ (V+) пристрій запускається самостійно, але відображає помилку F17.

**Діагностика:** 
- Підключення через програмне забезпечення Wonderfree (можливе зчитування БМС та інвертора окремо).
- Кодові версії обладнання: Інвертор — 106, БМС — 206.
- Процесор на платі інвертора: F280025PNS.
- Плата інвертора має ревізію P1800-PSDR-V1.2 (зазначено при заміні).

**Коди помилок:** 
F17 (з'являється при запуску напряму через V+).

**Деталі та аналоги:** 
- Плата інвертора: ревізія P1800-PSDR-V1.2.
- MCU на інверторі: F280025PNS (зазначено, що є нормальними для читання).
- Версії прошивок БМС та ІНВЕРТОРА зчитуються окремо.

**Покроковий ремонт:** 
1. Заміна плати інвертора на нову (ревізія P1800-PSDR-V1.2).
2. Спроба підключення через Wonderfree для отримання даних про версії.
3. Обговорення можливості затирання EEPROM на БМС (принцип FFFF) без фізичного втручання у нову плату інвертора.
4. Планування звернення до офіційних каналів для отримання прошивки по повітрю (поштою).

**Результат:** 
не вирішено в темі (автор шукає спосіб отримати прошивку або затерти EEPROM, фізичний ремонт не завершено).

**Застереження / нюанси:** 
⚠️ При процедурі затирання EEPROM на БМС серійник має залишитися, не зтирайте його.
⚠️ Версія прошивки може не впливати на роботу (зазначено у темі: різні версії працювали).
⚠️ Потрібно бути обережним при використанні інструментів для читання пам'яті, оскільки деякі рішення можуть коштувати дорого.
⚠️ Описана ситуація може вимагати фізичного втручання (перенесення даних), якщо програмний шлях не спрацює.
