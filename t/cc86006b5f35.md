**Пристрій / модель:** BLUETTI AC180P

**Симптом / несправність:** Необхідність відновлення прошивки, ідентифікація мікроконтролерів для можливого ремонту або заміни компонентів (тема стосується бекапу прошивок, а не конкретної поломки пристрою).

**Діагностика:**
- Використовувалася програма STM32CubeProgrammer.
- Інструмент: J-link для зчитування мікроконтролерів.
- **⚠️ потребує перевірки:** Початкова інформація від Jerry стверджувала про використання MCU серії STM32F10xx (Device ID 0x410), але потім Gennadiy58 уточнив реальні моделі на основі фізичного огляду.

**Коди помилок:** Немає інформації в темі.

**Деталі та аналоги:**
- **Панель (U2):** AT32F415CBT7 (версія прошивки V6.0).
- **Інвертор (M1):** AT32F423RBT7 (версія прошивки V6.0).
- **БМС:** EPROM Fm24c02.
- **Примітка:** Початкове твердження про STM32F10xx є помилковим для цієї конкретної версії, оскільки на платах встановлені мікроконтролери серії AT32 (Gennadiy58).

**Покроковий ремонт:**
- Зчитування дампу прошивки з мікроконтролерів.
- Підготовка архіву з різними варіантами прошивок (включно з калібруванням елементів інвертора від F.O.V).
- Перевірка наявності файлів у архіві (Gennadiy58 підтвердив, що всі потрібні прошивки є в одному місці).

**Результат:** Надано резервні копії прошивок для моделей AC180P (панель, інвертор, БМС). Питання щодо мікросхеми U1 залишилося відкритим через пошкодження корпусу/відсутність маркування.

**Застереження / нюанси:**
- ⚠️ Маркування мікроконтролерів на початку було неточним (STM32F10xx), потім коректно визначено як AT32F415CBT7 та AT32F423RBT7.
- Версії прошивок можуть відрізнятися залежно від модифікації плати (можливі варіанти з іншим маркуванням мікросхем).
- Для БМС використовується EPROM Fm24c02, що може бути важливо для заміни.
