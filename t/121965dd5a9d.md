**Пристрій / модель:** Bluetti AC200P, AC200MAX

**Симптом / несправність:** Збій роботи сенсорного екрану (тачскріна), необхідність заміни.

**Діагностика:** Перевірка сумісності шлейфів нового тачу з FPC конектором. Виміри електричних параметрів не наведені.

**Коди помилок:** Відсутні.

**Деталі та аналоги:**
- Оригінальний парт-номер тачу: YF04301-FPC V1 2206Z
- Замінний тачскрін: HST043060 23/06 (короткий шлейф, дістає до FPC конектора)
- Модуль DWIN комерційного застосування: DMG48270C043-03WTRZ20

**Покроковий ремонт:**
1. Заміна тачскріна на новий (HST043060 23/06).
2. Підготовка SD-картки: форматування у файлову систему FAT32 через командний рядок Windows (`format *: /FS:FAT32 /V:LCD /A:4096`).
3. Обсяг SD-картки має бути не більше 8 Гб.
4. Створення папки з назвою `DWIN_SET` на SD-картці.
5. Завантаження ядра (архів T5L_kernel) у модуль та зачекування оновлення.
6. Після оновлення видалення файлу ядра, завантаження файлу конфігурацій та виконання калібрування.

**Результат:** Калібрування проведено за інструкцією автора. Файли для оновлення (ядро, конфігурація) знаходяться у вкладеннях теми (доступні після авторизації).

**Застереження / нюанси:**
- Обов'язкове форматування SD-картки через командний рядок Windows (`format *: /FS:FAT32 /V:LCD /A:4096`).
- Розмір SD-картки не повинен перевищувати 8 Гб.
- ⚠️ Дата публікації теми (11.05.2026) вказує на можливу помилку у даних або майбутню дату, потребує перевірки актуальності інформації.
