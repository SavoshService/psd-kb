**Пристрій / модель:** Xiaomi POCO X3 Pro  

**Симптом / несправність:** Потрібно визначити номінали виділених елементів (резисторів), які були зняті під час зачистки плати.  

**Діагностика:**  
- Немає вимірювань, тестів чи інших даних.  
- На фото (не включено в розбір) видно два маленькі елементи, позначені як «виділені».  

**Коди помилок:** —  

**Деталі та аналоги:**  
- За підтвердженням учасників теми, це **прохідні резистори** (jumper‑резистори) з **номіналом 0 Ω**.  
- Такі резистори часто використовуються для «замикання» доріжок на платі (наприклад, підключення камер, антен, сенсорних модулів).  
- У схемах можуть позначатися як **0R**, **Jumper**, **Link**, **0 Ω**.  
- Аналоги: будь‑який 0 Ω SMD‑резистор (наприклад, 0402, 0603) або мікроскопічний провідник‑мостик.  

**Покроковий ремонт:**  
1. **Визначення типу елементу** – за зовнішнім виглядом (маленька SMD‑компонент‑пластина) і контекстом (розташування біля камер).  
2. **Підтвердження номіналу** – за допомогою бази даних схеми/маркера або простого вимірювання мультиметром (перевірка короткого замикання).  
3. **Встановлення** – при необхідності підпаїти новий 0 Ω SMD‑резистор у відповідне місце, дотримуючись полярності (для 0 Ω полярність не важлива).  

**Результат:**  
- Визначено, що обидва елементи – **прохідні резистори 0 Ω** (0R) по камерах.  
- Тобто їх можна замінити будь‑яким 0 Ω SMD‑резистором того ж розміру (наприклад, 0402).  

**Застереження / нюанси:**  
- Хоча 0 Ω резистори не мають опору, їх фізичний розмір і тип (SMD‑0402, 0603 тощо) мають відповідати оригіналу, інакше може бути проблеми з розташуванням або механічною міцністю.  
- При пайці слід уникати перегріву сусідніх елементів (особливо камер та сенсорних модулів).  
- Якщо на платі є кілька 0 Ω резисторів, важливо встановити їх у правильні позиції, бо вони можуть виконувати різні функції (з’єднання різних доріжок).  
- При підключенні нових елементів варто перевірити безперервність (мультиметром) після пайки, щоб впевнитися у правильному замиканні.
