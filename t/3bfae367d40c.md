**Пристрій / модель**  
- Програматор EG micro (програма для конфігурування плат **EGS005**, **EGS006**)  
- Плати, що підтримуються у наданих архівах: **EG8020**, **EG8025**, **EG1615**, **EG8026**  
- Запит щодо конфігуратора для **EG1155**  

**Симптом / несправність**  
- У темі не описано конкретної поломки пристрою.  
- Користувачі шукають **програмне забезпечення** та **апаратний інтерфейс** (конвертер рівнів сигналу) для підключення програматора до комп’ютера і налаштування параметрів плат.

**Діагностика**  
- Немає даних про вимірювання, тестування чи отримані значення.  

**Коди помилок**  
- Не зазначено.

| **Плати‑донори** | Не вказано конкретних донорських плат, лише зазначено, що програматор працює з платами **EGS005**, **EGS006**. |  |

**Покроковий ремонт** *(не застосовується, оскільки тема про налаштування, а не про поломку)*  
1. Під’єднати програматор до комп’ютера через **COM‑порт** або **USB‑UART** адаптер.  
2. При необхідності встановити **MAX232** (або інший рівневий конвертер) між TX/RX програматора і портом.  
3. Запустити програму `EG micro.exe`.  
4. Завантажити потрібний файл конфігурації з архіву (`EG8020_EG8025.rar` тощо).  
5. При необхідності скористатися перекладом UI (файл `1615` – картинки з перекладом).  

**Результат**  
- У темі не представлено готового рішення. **Не вирішено в темі**.  

**Застереження / нюанси**  
- Програма та інтерфейс **китайською** – без перекладу важко орієнтуватись; частковий переклад вже є у вигляді скріншотів.  
- Для успішного підключення потрібен **правильний рівень сигналу** (TTL ↔ RS‑232). Неправильний конвертер може пошкодити програматор або плату.  
- Якщо використовується USB‑UART адаптер, переконайтеся, що драйвери встановлені і порт правильно розпізнається ОС.  
- При роботі з різними моделями (EG8020, EG8025, EG1155) слід перевіряти сумісність файлів конфігурації – вони можуть мати різні параметри прошивки.
