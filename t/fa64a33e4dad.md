**Пристрій / модель:** EcoFlow Yeti 1000X (3000W). Контролер мікропроцесора: STM32F030R8T6.

**Симптом / несправність:** Відсутня прошивка для контролера первинної частини (керування MOSFET-ами підвищувача від АКБ, що розташовані між мідними шинами). Користувач має прошивку для синусової сторони, але потрібна саме для первинної логіки.

**Діагностика:** Визначено тип мікроконтролера на платі (STM32F030R8T6). Підтверджено наявність прошивки на іншій стороні (синус), відсутність — на первинній. КЗ по процесору не було, лише потрібні драйвер і логіка.

**Деталі та аналоги:** STM32F030R8T6. Файл прошивки: `yeti1000xniz.bin`.
