## 📋 Розбір теми «питання про акб матрис 4»

| **Розділ** | **Інформація** |
|------------|----------------|
| **Пристрій / модель** | DJI **Matrice 4** – акумулятор (АКБ) для квадрокоптера Matrice 4. |
| **Симптом / несправність** | Потрібно отримати доступ до файлів/даних у флеш‑пам’яті контролера батареї (чіп **Z2401**). Спроби «злити дампи» з флешки не дали результату – дані не читаються, батарея «заблокована». |
| **Діагностика** | * Виявлено чіп **Z2401** на платі акумулятора. <br>* Спроба зчитати флеш‑пам’ять через шину (ймовірно JTAG/SWD/I²C) – отримано лише кілька адрес, подальше сканування призводило до «зависа» («кірпіч»). <br>* Ніяких вимірювань напруг, опорів, температури в темі не зазначено. |
| **Коди помилок** | – (не зазначено). |
| **Деталі та аналоги** | * **Маркування чіпа:** **Z2401** – ймовірно мікроконтролер/Flash‑контролер, що використовується в акумуляторах DJI. <br>* **Флеш‑пам’ять:** містить «історію життя» акумулятора (кількість циклів, статуси, тощо) – називається «блек‑бокс». <br>* **Аналоги/донир‑плати:** в темі згадується, що військові розробили альтернативну плату, сумісну з Matrice, проте деталей (схеми, роз’єми) немає. |
| **Покроковий ремонт** | Ніяких успішних кроків у темі не описано. Є лише рекомендація **не** «чаклувати», бо можна зіпсувати робочий акумулятор. |
| **Результат** | **Не вирішено в темі** – жодного способу розблокування/зчитування даних не знайдено. |
| **Застереження / нюанси** | - **⚠️ Потрібна спеціалізована апаратура** (JTAG/SWD‑адаптер, програматор, можливо інструменти DJI SDK) та знання протоколу чіпа Z2401. <br>- **⚠️ Ризик блокування**: спроби сканування адрес можуть «завісити» контролер, що робить батарею невідновлюваною. <br>- **⚠️ Відсутність відкритих інструментів**: у відкритих джерелах немає готових програм/скриптів для читання/запису флеш‑пам’яті Z2401 (потрібен власний драйвер або інверсний інжиніринг). <br>- **⚠️ Альтернативна плата**: згадка про військову розробку не підтверджена, тому не варто розраховувати на її наявність без додаткових джерел. |
| **Висновок** | Тема містить лише загальну інформацію про проблему доступу до флеш‑пам’яті акумулятора Matrice 4 та попередження про небезпеку «чаклувань». Конкретних діагностичних даних, кроків ремонту чи рішень немає. Для подальшого розв’язання потрібне: <br>1. Точна ідентифікація чіпа Z2401 (даташит, інтерфейси). <br>2. Пошук або розробка програмного забезпечення для зчитування/запису флеш‑пам’яті. <br>3. Використання спеціалізованих програматорів та дотримання протоколу без сканування «всіх» адрес. |
