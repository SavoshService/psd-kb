## Розбір теми «WD3200BEVT 2.5 ″ — підключення до терміналу»

| **Пункт** | **Інформація** |
|---|---|
| **Пристрій / модель** | HDD 2.5 ″ WD3200BEVT, контролер‑плата **2060‑701499‑000 rev A** |
| **Симптом / несправність** | При подачі живлення шпиндель обертається кілька секунд, потім зупиняється. Диск **не розпізнається** через перехідник **SATA → USB** (SMART‑дані не читаються). Потрібен доступ до терміналу контролера для читання коду помилки та стану головок. |
| **Діагностика** | 1. **Swap‑плата** між двома дисками – виконано.<br>2. **Зчитування прошивки** з SPI‑флеш‑чипа – виконано (дамп отримано).<br>3. **Ініціалізація дампу** у терміналі на новій платі за допомогою **PC‑3000** – виконано, подальша діагностика не завершена.<br>4. **Підключення** через **SATA‑USB**‑адаптер – диск не розпізнається, SMART‑дані не читаються.<br>5. **Спроба** використати **USB‑TTL**‑адаптер (напруга < 5 В) – обговорювалося, але не підтверджено, що підключення вже здійснено. |
| **Коди помилок** | У темі не вказані конкретні коди помилок, які виводив би контролер. |
| **Деталі та аналоги** | * **Контактна розкладка**: потрібен «джампер» (зазвичай під’єднує землю), можливі 2‑3 контакти **Rx/Tx** для UART‑з’єднання.<br>* **Напруга** інтерфейсу UART – < 5 В (зазвичай 3.3 В або 1.8 В).<br>* **Програмне забезпечення**: <br> - **PC‑3000** (повний набір інструментів для читання/запису прошивки, ініціалізації, дампу).<br> - **WDMARVEL 2.3** – ATA‑термінал (читає/записує F/W, паспорт, діфект‑лісти).<br> - **beeprog2c + EV2400** – програматор/адаптер для розблокування дампу та роботи зі swap‑платами.<br> - **ACELAB PC‑3000** – професійна платформа, потребує великого набору донорів і досвіду.<br>* **Платформа для роботи**: рекомендовано **VIA Celeron 478 (socket 478)** – на нових чіпсетах (775, AMD/ATI) службові ATA‑команди часто блокуються. |
| **Покроковий ремонт** | 1. **Swap‑плата** між пошкодженим та робочим диском – здійснено, щоб перевірити, чи проблема в контролері.<br>2. **Зчитування SPI‑флеш** (дамп прошивки) – виконано за допомогою програматора.<br>3. **Розпакування та ініціалізація** дампу у терміналі (PC‑3000) – виконано, але без успішного відновлення.<br>4. **Підключення через SATA‑USB** – спроба, результат: диск не розпізнається, SMART‑дані відсутні.<br>5. **Обговорення придбання** спеціального обладнання (ACELAB PC‑3000, BGA‑машина, USB‑TTL адаптер).<br>6. **Використання beeprog2c + EV2400** – застосовано для swap‑плат і розблокування дампу, але без остаточного вирішення. |
| **Результат** | **Не вирішено в темі** – диск все ще не піддається діагностиці через SATA‑USB, необхідний спеціальний UART‑термінал (USB‑TTL) і відповідне ПЗ (WDMARVEL, PC‑3000). |
| **Застереження / нюанси** | - **USB‑TTL адаптер** повинен працювати з рівнем логіки ≤ 5 В (найчастіше 3.3 В або 1.8 В). Неправильна напруга може пошкодити контролер.<br>- **SATA‑USB**‑адаптери передають лише користувацькі ATA‑команди; службові (SMART, режим «read‑diagnostic») часто блокуються – тому через такий адаптер не вдасться отримати потрібну інформацію.<br>- Для успішного використання **PC‑3000 / WDMARVEL** потрібна **платформа з підтримкою VIA Celeron 478** (або інша, що дозволяє передавати службові ATA‑команди). На сучасних чіпсетах (Intel 775, AMD/ATI) це може не працювати.<br>- **Інвестиція в ACELAB PC‑3000** виправдана лише при наявності великого парку донорських плат і досвіду роботи; без цього вартість не окупається.<br>- При підключенні **UART‑кабелю** необхідно «видзвонити» (з’єднати) землю, інакше сигнал не буде стабільним.<br>- **Beeprog2c + EV2400** – ефективні для розблокування дампу, проте не замінюють повноцінний термінал для діагностики стану головок у реальному часі. |

> **Висновок:** Для подальшого відновлення WD3200BEVT потрібен **UART‑термінал** (USB‑TTL) з правильними рівнями напруги, підключений до відповідних контактів контролера, а також **програмне забезпечення** (WDMARVEL або PC‑3000) на сумісній платформі (VIA Celeron 478). Без цього діагностика через SATA‑USB неможлива, а інвестиції в дорогі професійні комплекси мають бути обґрунтовані наявністю достатньої кількості донорських плат.
