**Пристрій / модель**  
- Motorola E14 (XT2421‑15)

**Симптом / несправність**  
- Після спроби скидання FRP за допомогою UnlockTool телефон **не вмикається**.  
- При підключенні до ПК відображається як **sprd u2s diag** – пристрій «застряг» у режимі Diag.  
- Після прошивки (Pandora) телефон **завантажується**, Wi‑Fi працює, **мобільна мережа та Google‑сервіси не працюють**.  
- SIM‑картка розпізнається в boot‑menu, але **IMEI показує «ліві» значення**; команда `*#06#` виводить ID SIM‑картки, а не фізичний IMEI пристрою.  
- Дзвінки неможливі, мережа не підключається.

**Діагностика**  
- Підключення до ПК в режимі **sprd u2s diag** (USB‑diag).  
- Перевірка можливості входу в **fastboot** – не вдається.  
- Спроба прошивки різними інструментами: **Pandora (Box/Online), AMT, DFT, SM2, TSM**.  
- На останній прошивці **testpoint не спрацьовує** (не активується).  
- Відсутні вимірювані електричні параметри (напруга, опір тощо) у темі.

**Коди помилок**  
- Не зазначено.

**Деталі та аналоги**  
| Елемент | Коментар |
|--------|----------|
| **Pandora** | Онлайн‑версія та Pandora Box. Працює для прошивки, але не відновлює IMEI. |
| **AMT** | При прошивці «зависає на логотипі». |
| **Fastboot** | Не входить у режим. |
| **DFT / SM2 / TSM** | Згадуються як можливі інструменти, без конкретних результатів. |
| **Dump** | У користувача *leon67* є дамп прошивки **xt2421‑15 e14**. |
| **prodnv & nvitem** | Потрібні для відновлення (запит на бекап цих розділів). |
| **RPmb** | За словами одного учасника, для відновлення IMEI треба «скинути RPmb», а потім перепрограмувати IMEI (можливе пайка). |
| **Тест‑поінт** | На нових патчах вимкнений, тому не можна «запускати» прошивку через апаратний тест‑поінт. |

**Покроковий ремонт (те, що було спробовано)**  

1. **FRP‑reset** за допомогою **UnlockTool** → телефон не вмикається, діагностичний режим.  
2. **Підключення до ПК** → розпізнається як *sprd u2s diag*.  
3. **Прошивка через Pandora** (з використанням наявного дампу) → телефон завантажується, Wi‑Fi працює, **IMEI/мобільна мережа не працює**.  
4. **Спроба прошивки AMT** → зависає на логотипі.  
5. **Fastboot** → вхід неможливий.  
6. **Використання DFT, SM2, TSM** – лише згадано, без результатів.  
7. **Пониження (downgrade) прошивки** → testpoint не спрацьовує, NV‑розділи не записуються.  
8. **Обговорення RPmb‑wipe + перепрограмування IMEI** → потреба в пайці, вважається «зайвим»/дорогим (≈ 2 тис. грн).  
9. **Запити на бекап prodnv/nvitem** → не отримано.  

**Результат**  
- У темі **не знайдено остаточного рішення**.  
- Учасники планують здати пристрій без ремонту або залишити його «на розбір», оскільки вартість відновлення (особливо IMEI) вважається надто високою.

**Застереження / нюанси**  

- **Відновлення IMEI** на цьому моделi часто вимагає **запису RPmb** і **апаратного перепрограмування** (пайка/запис флеш‑модуля). Без спеціального обладнання це практично неможливо.  
- **Pandora** може прошити систему, але **не відновлює IMEI** і не гарантує роботу мережі.  
- На останніх патчах **testpoint вимкнено**, тому традиційний метод «запуску* через тест‑поінт*» не працює.  
- **Бекап розділів prodnv та nvitem** критичний для успішного відновлення, їх відсутність ускладнює процес.  
- **Спроба пониження прошивки** без успішного тест‑поінту часто призводить до того, що NV‑розділи не записуються («NV не пишеться»).  
- Якщо пристрій використовується в умовах **військових/службових** (згадка про роботу для військових), варто враховувати вимоги до безпеки та можливі обмеження на використання сторонніх інструментів.
