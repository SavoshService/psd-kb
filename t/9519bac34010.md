**Пристрій / модель:** Realme C53 (RMX3760)  

**Симптом / несправність:** Блокування мережі (carrier lock) – телефон не підключається до SIM‑карт інших операторів.  

**Діагностика:**  
- Використано програму **Unlocktool** (вкладка *Spreadtrum* → *Realme C53* → *Write RPMB*).  
- Завантажено файл **rpmb.img** (пакет `rpmb.rar`).  
- Після запису RPMB‑розділу блокування мережі залишилося.  

**Коди помилок:** – відсутні у темі.  

**Деталі та аналоги:**  
| Елемент | Опис |
|--------|------|
| Програмне забезпечення | Unlocktool (версія, що підтримує Spreadtrum/MediaTek) |
| Партіція | RPMB (Replay Protected Memory Block) – використовується для зберігання даних про блокування мережі |
| Файл прошивки | `rpmb.img` (запакований у `rpmb.rar`) |
| Аналоги | інші інструменти для розблокування (e.g., **MTK Droid Tools**, **SP Flash Tool**), проте у темі згадуються лише Unlocktool. |

**Покроковий ремонт:**  

1. **Підготовка**  
   - Завантажити `rpmb.rar`, розпакувати, отримати `rpmb.img`.  
   - Встановити Unlocktool, підключити телефон у режимі *download* (Fastboot/EDL).  

2. **Запис RPMB**  
   - У Unlocktool вибрати вкладку **Spreadtrum** → **Realme C53** → **Write RPMB**.  
   - Вказати шлях до `rpmb.img` і запустити процес запису.  

3. **Перевірка**  
   - Після завершення запису перезавантажити пристрій і перевірити стан мережі.  
   - У темі зазначено, що блокування залишилося.  

4. **Альтернативний підхід (згадано в темі)**  
   - Автор повідомив, що після оновлення безпеки в Unlocktool процес став **одним кліком**.  
   - Якщо користувач не має оновленої версії, пропонується виконати розблокування **віддалено** (деталі не наведені).  

**Результат:**  
- Перший метод (запис `rpmb.img`) **не вирішив** проблему – блокування мережі залишилося.  
- Пізніше автор заявив, що нова версія Unlocktool дозволяє розблокувати одним кліком, проте в темі немає підтвердження успішного виконання → **не вирішено в темі**.  

**Застереження / нюанси:**  
- **⚠️ потребує перевірки** – інформація про «один клік» в оновленій версії Unlocktool не підтверджена практичними результатами.  
- Запис у розділ **RPMB** – дуже чутливий процес; неправильний файл або перерване записування може **призвести до бракування пристрою** (brick).  
- Перед будь‑яким втручанням слід **зробити повний бекап** (наприклад, за допомогою `adb backup` або копіювання всіх розділів).  
- Реальна модель Realme C53 використовує **MediaTek Helio G85**, а не Spreadtrum; використання вкладки *Spreadtrum* в Unlocktool може бути помилковим або результатом старої/неофіційної прошивки.  
- Якщо телефон вже отримав **оновлення безпеки**, старі методи (запис RPMB) можуть бути заблоковані, тому потрібна актуальна версія інструменту.  
- Віддалене розблокування, пропоноване автором, потребує **повної довіри** до особи, що виконує операцію, та може порушувати умови гарантії або законодавство про розблокування мереж.
