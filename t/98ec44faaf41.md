**Пристрій / модель:**  
- MCU MEC1663 (використовується в ноутбуці **Lenovo T14 nm‑c931**, 1‑й покоління, Intel 10‑го покоління).  

**Симптом / несправність:**  
- Заблокований BIOS/UEFI (вимога вводу пароля). Потрібно зняти пароль без втрати даних.  

**Діагностика:**  
| Параметр | Значення / Коментар |
|----------|----------------------|
| Підключення | JTAG (TCK = 3 МГц) |
| MCU‑модель | **MEC1663** – **норма** |
| Сокет / джампери | TYPE A – **норма** |
| Пін‑розкладка | **норма** |
| Живлення MCU | **норма** |
| Ідентифікатор пристрою | `0x200024B1` – IR4 ARC600 core, ver.4 |
| ID пристрою | 66, ревізія 1, ID2 = `0x02202445` |
| Пам’ять Flash | Адреса 0x00000000, розмір 0x048000 байт (288 КіБ) |
| Пам’ять EEPROM | Адреса 0xE0000000, розмір 0x000800 байт (2 КіБ) |
| Дамп | 2048 байт (Flash + EEPROM) – файл у вкладенні `mec1663 NM-C931 rev10.rar` |
| Додаткова інформація | У EEPROM за **зміщенням 0x300** знаходиться зашифрований пароль. Для його видалення потрібно **стерти (записати 0xFF) ділянку до 0x370**.  |

**Коди помилок:**  
- В темі не вказано жодних кодів помилок.  

**Деталі та аналоги:**  
- **Зміщення 0x300** – типове місце зберігання пароля в MEC1663 (аналогічно іншим пристроям на цьому контролері).  
- **EEPROM 2 КіБ** – достатньо для зберігання BIOS‑пароля та налаштувань.  
- **Flash 288 КіБ** – містить BIOS‑образ, не використовується для зняття пароля.  

**Покроковий ремонт (згідно з постом):**  

1. **Підключення JTAG** до контролера MEC1663 (використовуючи сокет TYPE A, частота TCK = 3 МГц).  
2. **Зчитування пам’яті**:  
   - Flash 0x00000000 – 0x048000.  
   - EEPROM 0xE0000000 – 0x000800.  
   - Зберегти дамп (2048 байт) – файл у вкладенні.  
3. **Аналіз EEPROM**: знайти ділянку за **зміщенням 0x300** (відносно початку EEPROM).  
4. **Видалення пароля**:  
   - Записати значення `0xFF` (стерти) у діапазон **0x300 – 0x370** (включно).  
   - Це «затирання» зашифрованого пароля.  
5. **Перезапис EEPROM** (записати змінений блок назад).  
6. **Перезавантаження ноутбука** – BIOS/UEFI має запитувати новий пароль або працювати без нього.  

**Результат:**  
- У темі немає явного підтвердження успішності (наприклад, «пароль знято»). Тому в розділі **Результат** зазначено: **не вирішено в темі** (метод пропонується, результат не підтверджений авторами).  

**Застереження / нюанси:**  

- **Бекап**: перед будь‑якими записами обов’язково робити повний дамп Flash + EEPROM.  
- **JTAG‑параметри**: використання неправильного такту (TCK) може пошкодити контролер.  
- **Діапазон стирання**: стирати треба лише до **0x370**; більший діапазон може знищити інші налаштування (наприклад, серійний номер, MAC‑адреси).  
- **Зашифрований пароль**: метод працює лише для даної ревізії (rev 10) контролера; інші ревізії можуть мати інше розташування/шифрування.  
- **Відновлення**: після стирання пароля можливо доведеться заново налаштувати BIOS (дата/час, порядок завантаження).  
- **Ризик**: неправильне підключення JTAG або помилковий запис у Flash може зробити пристрій нефункціональним і вимагати перепрошивки BIOS.
