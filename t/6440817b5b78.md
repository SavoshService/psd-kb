**Пристрій / модель:** ZTE A51  

**Симптом / несправність:**  
Потрібно перепрошити телефон на європейську (Poland) прошивку. Технічних скарг чи помилок у темі не зазначено – користувач просто шукає спосіб зміни регіональної прошивки.

**Діагностика:**  
У темі не вказано жодних вимірювань, тестів чи діагностичних даних.

**Коди помилок:**  
Відсутні.

**Деталі та аналоги:**  
- Файл прошивки називався **Update.zip**.  
- Рекомендовано розпакувати архів на **чисту флеш‑карту** (SD‑card) і встановлювати через **Recovery → Install update from SD**.  
- У одному з дописів зазначено, що це **«без NFC з Польщі»** – тобто прошивка не потребує NFC‑модуля.  

**Покроковий ремонт:**  
1. Скачати потрібний файл прошивки (у темі зазначено, що файл більше не доступний).  
2. Розпакувати архів і скопіювати **Update.zip** на чисту SD‑карту.  
3. Завантажити телефон у режим **Recovery**.  
4. Вибрати **Install update from SD** і вказати файл **Update.zip**.  
5. Дочекатися завершення процесу і перезавантажити пристрій.  

**Результат:**  
У темі не вказано, чи вдалося успішно прошити пристрій. Останній допис повідомляє, що файл більше недоступний, тому результат **не вирішено в темі**.

**Застереження / нюанси:**  
- Потрібно мати **чисту** (порожню) SD‑карту, щоб уникнути конфліктів під час інсталяції.  
- Якщо файл прошивки недоступний, треба шукати альтернативне джерело (офіційний сайт ZTE, форуми XDA, інші репозиторії).  
- Перед прошивкою варто **зробити резервну копію** даних, оскільки процес стирає користувацькі дані.  
- Переконайтеся, що вибрана прошивка саме для **європейської (Poland) моделі** телефону, інакше можливі проблеми з сумісністю (наприклад, різні частоти LTE).
