## Розбір теми «Dump матриці HW14WX101 (BOE‑Hydis) / P140NWR1 (IVO)»

| Пункт | Інформація |
|-------|------------|
| **Пристрій / модель** | **HW14WX101** – 14‑дюймова Slim LED‑матриця, 40‑контактна, виробник **BOE‑Hydis** (фізична наклейка). У прошивці матриці вказано **P140NWR1** – модель від **IVO** (ID в прошивці: IVO0579). |
| **Симптом / несправність** | У посту не вказано конкретну поломку, проте автор зазначає, що дамп EDID може бути корисним для **відновлення коректної роботи** (регулювання яскравості, правильне розпізнавання системою) у ноутбуках, де встановлена ця панель. Тобто типова проблема – **невірне або відсутнє розпізнавання матриці ОС/BIOS**, що проявляється у відсутності регулювання яскравості, неправильному відображенні кольорів, або взагалі “black screen”. |
| **Діагностика** | У темі немає опису проведених вимірювань чи тестів. Є лише **дамп EDID** у вигляді файлу `HW14WX101.BIN`, який, ймовірно, був отриманий за допомогою програмного забезпечення (наприклад, `ddcutil`, `Phoenix EDID Designer` або апаратного програматора EEPROM). |
| **Коди помилок** | – |
| **Деталі та аналоги** | - **Маркування на наклейці:** HW14WX101 (BOE‑Hydis)  <br>- **ID в прошивці:** IVO0579 / P140NWR1 (IVO)  <br>- **Тип:** 14.0" Slim (LED), 40‑pin  <br>- **Роздільна здатність:** 1366 × 768 (HD)  <br>- **Частота оновлення:** 60 Hz  <br>- **Застосування:** ультрабуки ASUS серії **U46 / U47** (можливі інші ноутбуки з 14‑дюймовим 1366×768 дисплеєм).  <br>- **Аналоги:** схожі 14‑дюймові панелі BOE‑Hydis та IVO з тим же роз’ємом (наприклад, HW14WX101‑A, P140NWR1‑B). |
| **Покроковий ремонт** | У темі не наведено конкретних дій. Нижче наведено типову послідовність, яку можна застосувати, використовуючи наданий дамп EDID:  <br>1. **Підготовка** – зняти панель, підключити її до програматора EEPROM (наприклад, CH341A, TL866).  <br>2. **Бекап** – зчитати поточний EDID (записати у файл `original.bin`).  <br>3. **Перевірка** – порівняти контрольні суми (CRC) оригіналу та дампу; переконатися, що розмір/структура відповідає 128 байт (або 256 байт для розширеного EDID).  <br>4. **Запис** – записати файл `HW14WX101.BIN` у EEPROM панелі.  <br>5. **Перевірка** – після запису знову зчитати EDID, переконатися у збігу контрольних сум.  <br>6. **Тестування** – встановити панель у ноутбук, перевірити: <br>   • розпізнавання роздільної здатності 1366×768; <br>   • можливість регулювання яскравості через клавіші/OS; <br>   • відсутність артефактів/збоїв. |
| **Результат** | У темі немає інформації про результат виконання будь‑яких дій. **Не вирішено в темі**. |
| **Застереження / нюанси** | - **Ризик**: неправильний дамп або помилка під час запису може зробити панель **невикористовуваною** (втрата EDID → “black screen”).  <br>- **Контрольна сума**: перед записом обов’язково перевіряти CRC (використовувати інструменти типу `edid-decode`).  <br>- **Сумісність**: хоча фізичне маркування HW14WX101 (BOE‑Hydis), в прошивці вказано P140NWR1 (IVO). Переконайтеся, що BIOS/UEFI ноутбука підтримує дану комбінацію (можливі випадки, коли BIOS очікує конкретний Vendor ID).  <br>- **Запасний EDID**: зберігайте оригінальний дамп, щоб мати можливість повернутися до нього у випадку проблем.  <br>- **Використання**: даний дамп корисний лише для **встановлення** у ноутбуки, які вже фізично підтримують цю панель (роз’єм, напруга, таймінги).  <br>- **Перепрошивка без потреби**: якщо система вже правильно розпізнає панель, перепрошивка не потрібна і може лише ускладнити ситуацію. |
| **Примітка** | Тема містить лише **один пост** з дампом EDID та коротким описом. Ніяких діагностичних вимірювань, кроків ремонту чи результатів не наведено.  |
