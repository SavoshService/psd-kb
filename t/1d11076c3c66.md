### Застереження / нюанси  
- **⚠️ Потрібно перевірити**: чи відповідає файл `*.extcsd` формату, який підтримує ваш інструмент для подальшого відновлення (наприклад, `fastboot flash` чи спеціальний скрипт).  
- При роботі з eMMC‑чипом **не допускайте статичної розрядки** – використовуйте антистатичний браслет та заземлення.  
- **Write‑Protection** вимкнено, проте перед записом нових даних варто ще раз перевірити статус `Permanent Write Protection` та `Temporary Write Protection`.  
- Якщо планується **заміна eMMC**, необхідно **переписати таблицю розділів** (GPT/MBR) у новому чипі, інакше пристрій може не завантажитися.  
- При конвертації MBR → GPT (як у виводі) важливо переконатися, що **Boot Partition** вказаний правильно (`ROM2`), інакше завантажувальна послідовність може бути порушена.
