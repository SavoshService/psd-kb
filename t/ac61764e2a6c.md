**Розбір теми «Взаимозаменяемость egs005» (BlackBee 1000, інверторний модуль Egs005)**  

---

## Пристрій / модель
| Параметр | Дані |
|----------|------|
| **Бренд / модель** | Alpha‑ESS **BlackBee 1000** (портативна зарядна станція) |
| **Інверторний модуль** | **Egs005** (різні ревізії: оригінальна, замінна з OLX, **EGS06**, **egs005q**) |
| **Мікросхеми** | EG8025 (програмована на 12 V/220 V), EG8015 (вставлена у готову плату) |
| **Додаткові плати** | EGS06 (інша ревізія), egs005q (змінна ревізія) |
| **Транзистори‑ключі** | MOSFET NCE30TD60BT (високовольтний блок) |
| **Шунти вимірювання струму** | 0,01 Ω 5 % (стандарт), 0,01 Ω 1 % (після заміни) |
| **UART‑інтерфейс** | UART‑вихід до двох роз’ємів (основний + 4‑піновий), сигнал **RUN** – 27‑й контакт процесора → оптрон інвертора |

---

## Симптом / несправність
| № | Опис |
|---|------|
| 1 | Після заміни модуля **Egs005** інвертор стартує, працює без навантаження, а при навантаженні ≤ 60 Вт переходить у захист (вимикається через ~2 сек). |
| 2 | При підключенні лампи 60 Вт інвертор працює, дисплей показує **118 Вт** (при правильних шунтах). |
| 3 | При підключенні лабораторного джерела **25 В** інвертор у захисті; при **21 В** – нормальний запуск. |
| 4 | При 80 % SOC без навантаження напруга на шинах до 440 В, при 99 % SOC – до 460 В. |
| 5 | Зелене LED (SV) – нормальна робота до **+439 В**, червоне LED – захист при **≥ 440 В**. |
| 6 | Після підключення нової плати інвертор формує синус, але самовимикається (незалежно від навантаження). |
| 7 | У тестовому режимі (програма **eg8025**) інвертор вимикається через ~2 сек, без повідомлень про помилки; читає неправильну температуру. |
| 8 | При вимірюванні гейт‑сигналів MOSFET‑ів – «якась фігня», один з чотирьох транзисторів не реагує. |
| 9 | Після додавання резистора **22 kΩ** у ланцюг **+400 V** на вході **Egs005** інвертор працює (без резистора вимикався через 1 с). |

---

## Діагностика
| Дія | Результат / виміряні значення |
|-----|-------------------------------|
| **Вимір шунтів** | 0,01 Ω 5 % → 98 Вт при 60 Вт навантаження; 0,01 Ω 1 % → 118 Вт при 60 Вт. |
| **UART‑лог** | `BYTE10 Fault Code 0x05` – *Under Voltage of DC bus*; `BYTE5‑6 DC‑bus Voltage = 0x084D = 212,5 В`; `BYTE1‑2 Output Voltage = 0x056A = 138,6 В`. |
| **Резистивний дільник** (на новій платі) – R34=R35=300 kΩ, R38=R39=510 kΩ, R40=200 kΩ, R41=150 kΩ. Оригінальна плата – R34=R35=200 kΩ, R38=R39=200 kΩ, R40=0 Ω, R41=0 Ω. |
| **Пошкоджені елементи** | Два згорілі 10 kΩ резистори на підміненій платі. |
| **Програмне налаштування** | Чіп EG8025 налаштований на 12 V/220 V (не підходить до 24 V батареї). |
| **Тестовий режим (eg8025)** | Коди помилок: 0x4 – *high input voltage*; 0x5 – *low input voltage* при різних значеннях `max voltage`. |
| **Високовольтна шина** | Виміряно 420 V (мультиметр), запитувана 450 V у тестовому режимі. |
| **Налаштування Adv Settings** | `max voltage 2/1` спочатку 4400/4200 (≈ 440/420 V) → інвертор не стартував; підвищено до 4600/4400 (≈ 460/440 V) → інвертор працює; при 4700/4500 (≈ 470/450 V) → код 0x5, інвертор не стартує. |

---

## Коди помилок
| Код | Текст (з UART) | Тлумачення |
|-----|----------------|------------|
| **0x05** | Under Voltage of DC bus | Напруга шини нижче мінімальної (виявлено при запуску). |
| **0x04** | High Input Voltage | Висока вхідна напруга (з'являється при налаштуванні `max voltage` > реальної). |

## Результат
- **Поточний стан (за темою)**: інвертор **може працювати стабільно** після:
  1. Заміну шунтів на 0,01 Ω 1 %;
  2. Корекції резистивного дільника (значення, як на новій платі);
  3. Підвищення параметрів захисту шини (`max voltage 2 = 4600`, `max voltage 1 = 4500`);
  4. Додавання резистора **22 kΩ** у ланцюг +400 V (для плати EGS06).  

- **Незавершені питання**:  
  - Потрібна перепрограмування/заміна чіпа **EG8025** на конфігурацію 24 V/230 V (для оригінальної плати).  
  - Питання сумісності пін‑розташування процесора при заміні на інші ревізії залишилось відкритим.

## Застереження / нюанси
- **⚠️ потребує перевірки**: точність коду 0x05 (Under Voltage) – може бути викликано не лише низькою напругою шини, а й помилковим масштабуванням дільника (різні значення резисторів на різних ревізіях).  
- При роботі з **високою напругою (≥ 400 V)** обов’язково використовуйте ізольовані пробники та захисні рукавички.  
- **UART‑програмування** без правильних параметрів (напруга, частота) може «записати» неправильну конфігурацію, що призведе до захисту інвертора.  
- **Шунти** повинні мати точність **≤ 1 %** – інакше вимірювана потужність буде заниженою, а контролер може сприймати це як перевантаження.  
- При заміні **модулів** (Egs005 ↔ EGS06 ↔ egs005q) слід перевіряти **розташування пінів RUN, TXD0, RXD0** – їх несумісність може призвести до відсутності відображення навантаження на дисплеї.  
- **MOSFET NCE30TD60BT** має значний холостий струм (~100 Вт) – при довготривалій роботі без навантаження може перегріватися, що впливає на захисний таймер.  
- При налаштуванні **high‑bus voltage protection** не слід підвищувати значення вище реальної максимальної напруги батареї (≈ 460 V) – інакше інвертор може не виявляти реальної аварійної ситуації.  
- **Тестовий режим** (програма *eg8025*) слід запускати **без підключених MOSFET‑ів** – це дозволяє виключити їхню несправність і перевірити лише логіку контролера.
