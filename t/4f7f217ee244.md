**Пристрій / модель:** Realme X7 Pro (RMX2121)  

**Симптом / несправність:** Блокування мережі (SIM‑блок, прив’язка до оператора).  

**Діагностика:** у темі не вказано жодних вимірювань, логів чи кодів помилок.

**Деталі та аналоги:**  
- Файл, який пропонується для розблокування — `oplusreserve1.img`.  
- Файл входить до архіву `RMX2121 Unlock Sim.7z`.  
- Пропонується два варіанти застосування:  
  1. **Пряме прошивання** у відповідний розділ (partition) пристрою.  
  2. **Замінити** файл у прошивці, відредагувавши `scatter`‑файл (файл розподілу розділів).  

**Покроковий ремонт:** (згідно з постом)  

| Крок | Опис |
|------|------|
| 1 | Завантажити архів `RMX2121 Unlock Sim.7z` і розпакувати `oplusreserve1.img`. |
| 2 | Визначити, який розділ у прошивці відповідає за блокування мережі (зазвичай це `reserve1` або `oplusreserve1`). |
| 3 | **Варіант A:** за допомогою інструменту типу **SP Flash Tool** вибрати режим *Download*, підключити телефон у режимі fastboot, вказати `oplusreserve1.img` у відповідному полі розділу і запустити прошивання. |
| 4 | **Варіант B:** відкрити оригінальний `scatter`‑файл прошивки, замінити шлях до файлу `reserve1.img` (або аналогічного) на `oplusreserve1.img`, зберегти `scatter` і прошити всю прошивку через SP Flash Tool. |
| 5 | Після завершення прошивки перезавантажити пристрій і перевірити, чи працює SIM‑картка в будь‑якій мережі. |

**Результат:** У темі не зазначено, чи успішно пройшло розблокування. → *не вирішено в темі*.  

**Застереження / нюанси:**  
- **⚠️ Потрібно робити резервну копію** оригінальної прошивки та важливих даних (фото, контакти) – процес прошивки стирає дані.  
- Неправильний вибір розділу або помилкове редагування `scatter`‑файлу може **привести до браку** (brick) пристрою.  
- Після прошивки може знадобитися **перепрошивка модему** (baseband) або **перезапуск мережевих налаштувань** у Android (Settings → Network & internet → Mobile network → Reset).  
- Даний метод працює лише для **моделі RMX2121**; інші варіанти X7 Pro (наприклад, інший регіональний код) можуть мати інший розділ або інший файл блокування.  
- Використання **неофіційних файлів** може порушити гарантію та/або викликати проблеми з оновленнями OTA.
