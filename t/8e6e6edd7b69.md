**Пристрій / модель**  
- EcoFlow **Delta EF3 Pro** 1260 Wh (інвертор).  
- На платі контролера згадується **MR300‑CNTL‑V1.0.2** та **MR310‑INV‑F303** (модуль GD32F303RC/STM32F303RC).  

**Симптом / несправність**  
- Інвертор «мертвий»: не вмикається, навіть після заміни процесора (MCU).  
- Після прошивки зелений діод блимає, але інвертор не запускається.  

**Діагностика**  
| Крок | Що робили | Результат |
|------|-----------|-----------|
| 1. Замінено процесор (MCU) на новий GD32F303RC. | – | Інвертор залишився неактивним. |
| 2. Завантажено файл **DELTA 1260 Inverter.bin** (припускається «робоча» прошивка). | Флеш‑програмою (не вказано яку) записано у GD32F303RC. | Зелене світло миготить, інвертор не стартує. |
| 3. Перевірка сумісності прошивки: | Порівняно назву файлу з відомими прошивками. | Виявлено, що файл відповідає контролеру **MR310‑INV‑F303** (GD32F303RC/STM32F303RC). |
| 4. Порівняно з іншими контролерами (MR300‑CNTL‑V1.0.2). | – | Невідповідність контролерів ускладнює перевірку. |

**Коди помилок**  
- Не зазначено жодних кодів помилок у темі.  

**Деталі та аналоги**  
- **Контролер MR300‑CNTL‑V1.0.2** – використовується в деяких версіях Delta EF3 Pro.  
- **Контролер MR310‑INV‑F303** – інша версія, базується на мікросхемі GD32F303RC (сумісна зі STM32F303RC).  
- Файл **DELTA 1260 Inverter.bin** виявився дампом/прошивкою саме для **MR310**, а не для MR300.  
- У Delta Max (інша модель) використовується схожа прошивка, що могло спричинити плутанину.  

**Покроковий ремонт** (теоретичний, на основі обговорення)  
1. **Визначити тип контролера** на конкретному інверторі (зчитати маркування MCU, номер ревізії плати).  
2. **Підготувати відповідну прошивку**:  
   - Якщо контролер MR300‑CNTL‑V1.0.2 → потрібна прошивка для MR300.  
   - Якщо контролер MR310‑INV‑F303 → потрібна прошивка для MR310.  
3. **Перевірити цілісність файлу прошивки** (контрольна сума, порівняння з офіційними дампами).  
4. **Підключити програматор** (ST‑Link, J‑Link, або спеціальний GD32‑програматор).  
5. **Завантажити прошивку** у режимі **erase‑all → program → verify**.  
6. **Перевірити індикатори** (зелене діодне світло, індикатори живлення).  
7. **Тестовий запуск**: підключити акумулятор, ввімкнути інвертор, спостерігати за стартом та вихідними параметрами.  
8. Якщо інвертор не стартує, **перевірити живлення MCU**, напруги на VCC, VDD, а також сигнали reset/boot.  

**Результат**  
- У темі **не знайдено успішного вирішення**.  
- Файли прошивки виявлені невідповідними до контролера інвертора, тому інвертор залишився неактивним.  

**Застереження / нюанси**  
- **⚠️ потребує перевірки**: точна модель контролера (MR300 vs MR310) у конкретному Delta EF3 Pro. Без цього будь‑яка прошивка може пошкодити пристрій.  
- При флешуванні **незмінна відповідність MCU та прошивки** – навіть схожі мікросхеми (GD32F303 vs STM32F303) можуть мати різні розташування регістрів/пам’яті.  
- **Ризик «brick»** – неправильна прошивка може зробити контролер непрацездатним, що потребуватиме спеціального режиму **bootloader** або заміни MCU.  
- При заміні процесора слід **перевірити пайку та підключення** (особливо контакти VDD, GND, BOOT0).  
- Якщо індикатор лише блимає, це часто ознака **запуску bootloader**, а не повноцінного виконання прошивки.
